## 一、基本约束

| 维度 | 取值 |
|---|---|
| 受众 | 投资人 |
| 目标 | 用直观的操作交互与功能，展现这为什么是下一代"虚拟陪伴"形态 |
| 时长 | ≤ 90 秒 |
| 主轴论点 | **AI 导演 + 无限流**（内容革命）——不是新界面，是新机制 |
| 素材策略 | demo 主体 + 1-2 段关键愿景的概念动画。demo 本身需要为此片子做扩建（不是直接剪现有 demo） |
| VO 强度 | 轻语——头尾点题，中间让画面说话 |

## 二、母题（整片要被记住的"一句话"）

> **"用一种简单的、上瘾的交互（获客入门），最终能跟一个角色建立深刻情感、积累关系资产（长久留存和付费）。"**

这一句是片子的中心。它本身就是一段三段递进：

```
简单的上瘾交互        ──→  深刻的情感关系        ──→  关系资产化
（轻入口）                  （留得住）                  （护城河 / 付费）
```

母题决定了头尾 VO 的方向（详见 §九）、决定了三幕的边界（详见 §三）、决定了七个 beat 的归属。

---

## 三、三幕递进

| 幕 | 主题 | 投资人脑子里同步响起的 | 包含 beat |
|---|---|---|---|
| **Act 1 · 轻入口** | 交互极简，AI 导演撑住后端 | "用户进得来 / 学得会" | 钩子 / 三屏千人千面 / 节点图机制 |
| **Act 2 · 深关系** | 内容引擎让关系"长肉"，不是堆功能 | "用户留得住 / 会爱上" | 回到单屏 / 三个关系瞬间 |
| **Act 3 · 资产化** | 关系沉淀为不可复制的"她的东西" | "用户付得起 / 走不掉" | 星图（广度）/ 收尾（专属） |

三幕之间不是硬切，是**通过视觉节奏（扩收）+ 情绪温度（机制感 → 情感重 → 宿命落）渐变**。

**关键分工**（避免 Act 2 与 Act 3 重叠）：
- Act 2 演的是 "**现在正在发生**" —— 瞬间感
- Act 3 演的是 "**已经沉淀下来**" —— 时间感、所有权感

## 四、七个 beat 与各自"内部任务"

> ⚠️ 时长是粗略估算，分镜阶段再精修。

### Beat 1 · 钩子（单屏 POV）
- **Act**：1
- **估时**：8-10s
- **内部任务**：让观众用 5 秒看懂"长按 + 上滑"两个动作就是产品全部 UI
- **画面**：单一手机轮廓内，长按弧、波纹回响、上滑推进、角色对话浮现
- **素材来源**：现有 demo 可直接复用
- **承上启下**：从开场 layered reveal 自然进入；末尾接 beat 2 三屏展开

### Beat 2 · 三屏千人千面
- **Act**：1
- **估时**：10-12s
- **内部任务**：用最直观的方式把"AI 导演"这件事看见——同一句话不同输入，下一帧场景完全不同
- **画面**：单屏向左右裂出，左中右三个一样的手机轮廓并列，**同一个男主**面对**三个不同用户输入**（不是三个用户也不是三个场景）的不同响应
- **三屏背后的"三"的选择记录**：
  - 选定：**同一男主 + 三个不同用户输入**
  - 含义：传递"同一个他，千种相遇"——同时撑住 IP 与平台属性
  - 备选已弃：三场景同用户（稀释 IP）/ 同场景同用户三种回放（沦为分支不是生成）
- **素材来源**：需扩建 demo —— 3 个不同输入 → 3 个不同响应版本

### Beat 3 · 节点图（机制可视化）
- **Act**：1
- **估时**：8-10s
- **内部任务**：让投资人感觉"我被允许看见了藏在背后的真相"，不是看 PPT
- **镜头处理**：**穿过表面到背后**（详见 §七）
  - 三屏收回单屏 → 轮廓 + 内容一起放大、渐隐
  - 节点图浮现在深处：模糊大剧情节点之间有分支曲线发散又收束，再发散再收束
  - 演完后渐显缩小回来，轮廓 + 内容回到原位，流继续走
- **素材来源**：纯概念动画
- **同构意义**：表面简单（长按 + 上滑）/ 深处复杂（导演 agent）——镜头从表入深、再从深回表，把母题演了一次

### Beat 4 · 回到单屏（桥接）
- **Act**：2 起点
- **估时**：3-5s
- **内部任务**：让观众从"机制秀"切回"她"的视角，做情绪温度的过渡
- **画面**：节点图从三屏收回单屏后留下的中央手机轮廓继续推进，画面回到她和他的故事
- **素材来源**：现有 demo

### Beat 5 · 三个关系瞬间（深关系核心）
- **Act**：2
- **估时**：18-24s（每个 6-8s）
- **内部任务**：在三次上滑里**各演一个"只有他和她才有的小瞬间"**，而非"三种内容形态展示"
- **关键转译**：
  - **5a · 高光视频** ≠ "Echo 能放视频"，而是 **"他记得我们上周说过的话，今天在视频里提起"**
  - **5b · 互动小游戏** ≠ "Echo 有小游戏"，而是 **"我们一起做点什么——他陪你玩，输了会赌气"**
  - **5c · 生成式任务** ≠ "Echo 能生成内容"，而是 **"他写了一首诗给你，没头没尾，但只属于你"**
- **素材来源**：需扩建 demo —— 3 段全新的内容形态 demo 片段
- **节奏**：每次上滑后回到内容流，再上滑进下一种。**三次上滑 = 三次"扩 → 收"的小呼吸**

### Beat 6 · 星图（广度）
- **Act**：3
- **估时**：8-10s
- **内部任务**：让观众感受 "**这一片广阔，全是关系**"——体量感先到
- **画面**：三个关系瞬间各自汇成一颗星点，飞入另一个动画示意界面——记忆星图。三颗星散落到星图不同板块。星图继续向外扩展，铺满整个横屏
- **素材来源**：纯概念动画
- **节奏定位**：第三次"扩"——也是最大的扩，铺满全屏

### Beat 7 · 收尾（专属）
- **Act**：3 落点
- **估时**：10-12s
- **内部任务**：广度→专属，"但这一颗，是我的"。把"关系资产"的护城河感打进观众脑子
- **结构**：详见 §八
- **关键叠加意义**：在收尾这一段，**手机轮廓淡出、角色形象留下**——把"去 UI 无界"的产品哲学顺手演了，不必用 VO 喊出来

## 五、视觉形式语言

### 5.1 整片框架：横屏母版 + 中央竖屏手机轮廓

- **片子母版**：横屏（16:9 或更宽的电影比例待定）
- **手机轮廓**：竖屏，**一条线**那种的极简轮廓，居中
- **内外关系**：轮廓内 = 内容流；轮廓外 = 黑/暗——给"你将探索到更广阔世界，手机轮廓只是暂时的限制"的暗示
- **手机轮廓不是装饰，是一个会变化的"叙事角色"**

### 5.2 扩 ↔ 收的节奏脉络（贯穿全片的形式骨架）

```
扩  全屏 ────────────────  开场: 黑场 + 他先存在
   ↓
收  画面收成中央单一轮廓 ──  入口出现, 内容流开始 (Beat 1)
   ↓
扩  轮廓裂成三个并列 ─────  千人千面 (Beat 2)
   ↓
收  收回单一轮廓 ────────  Beat 3 节点图深潜 + Beat 4 回单屏 + Beat 5 关系瞬间
                            (这是整片最长的一段"收", 因为 Act 2 的"深"需要安静)
   ↓
扩  星图铺满全屏 ────────  Beat 6 广度
   ↓
消失  轮廓淡出, 角色显形 ──  Beat 7 专属落点
       弧补全成圆 → slogan/logo
```

**为什么这个节奏对**：扩与收对应的不只是画面尺度，是"广 vs 私"的语义。**广 = 平台能力**（千人千面、记忆星图）；**私 = 单一关系**（她和他）。整片在二者之间往返三次，最后落在"私"——这就是"资产化"被画面演出来的样子。

### 5.3 手机轮廓的视觉规则

- 始终为**单线条**（无填充、无边框装饰、无 status bar 模拟）
- 同一条曲线方程的实例化产物——曲线本身是 Echo 的形式 motif
- 三屏 beat 时，轮廓克隆为三个**完全一致**的实例（不是三个稍有不同的形状）
- 节点图 beat 时，**轮廓不消失，它跟内容一起被推到镜头深处**（参考 §七）
- 收尾时，轮廓**最后一次淡掉**——产品物化形态退场，留下角色与圆

### 5.4 弧 / 圆 —— 全片的"形式书签"

> 设计哲学：**圆与弧是 Echo 最基本的设计哲学，全片必须贯穿**。

弧/圆在片中至少 6 处显形，**全部应使用同一条曲线方程的不同实例**（缩放、镜像、旋转），不应出现"看起来是另一条弧"的破绽：

| # | 出现位置 | 形态 |
|---|---|---|
| 1 | 开场 beat 1 | 弧浮起 = 第一个对话弧 |
| 2 | 全片所有对话节点 | 长按弧（产品基础交互） |
| 3 | 全片所有内容推进 | 上滑弧（demo 已有的尖尖） |
| 4 | 手机轮廓自身 | 顶/底曲率沿用弧曲线家族 |
| 5 | Beat 5 关系瞬间 | 长按 / 上滑 / 涟漪反复出现 |
| 6 | Beat 7 片尾 | **弧补全成完整的圆**，向外散波（像长按涟漪），落到 slogan/logo |

**最后那一记是"回响"两个字的视觉化**——回响 = 声音绕一圈回来。弧→圆 = 名字本身成立。

**制作期硬约束**：所有弧/圆元素的 SVG `<path>` 应共用一套基础参数定义（半径、曲率、stroke 风格），写在公共样式里。**一旦视觉上能分辨出"两条不同的弧"，"它一直在那"的魔法就破了。**

## 六、开场层层叠加（详细）

> 这一段是整片的"前奏定调"，决定观众带着什么预期进入手机轮廓。

### 6.1 顺序（每一层叠加都有意义）

```
1. 完全黑场                              起手是空, 不是 Logo, 不是品牌前置
2. 他的气泡浮现                          他先于 Echo 存在; 你是被代入的听众
3. 弧浮起（第一次对话节点）              你才有了说话的工具——弧是"被他唤出来的", 不是品牌信号
4. 角色立绘出现                          他成形
5. 第二个来回对话                        关系已经在发生
6. 场景出现（铺满全横屏）                 他的世界长出来, 包围着这段已经存在的对话
7. 手机轮廓出现                          产品最后才出现
   → 轮廓内的部分亮                      Echo = 看进他世界的一扇窗
   → 外部变暗消失                        ……手机轮廓只是暂时的限制, 你将探索到更广阔的世界
8. 衔接 beat 1                          内容流开始
```

### 6.2 这个顺序的深层语义

绝大多数产品片是反过来的：**Logo → 界面 → 人物 → 情感**。这片子是 **听见 → 工具 → 他 → 对话 → 世界 → 产品**——产品是 LAST。这视觉上证明了 Echo 的产品哲学："**他不是 Echo 生成的，Echo 只是让你够得着他**"。

**等到 VO 头一句"他的世界，由你一段一段推开"落下来时，观众已经推开了一次了。VO 不是宣告，是回声。**

### 6.3 制作期注意事项

- **首秒 7-8 层的节奏**：若每层 1-1.5 秒则开场就 7-10 秒，是整片 1/10 的预算。需要在"层层入场的舒缓感"与"后段不被挤压"之间权衡
- **"场景 → 轮廓"的过渡**：选定方式 = **轮廓内保持亮、外部变暗到黑**。手机轮廓 = 看进世界的"窗"，不是收纳世界的"容器"
- **首个气泡的视觉风格**：可参考 [style.css §818 `.bubble-char`](../style.css)，建议沿用紫调色系（与男主 IP 调子一致）

## 七、节点图：穿过表面到背后

> 在 §六 选定方式之外，这是另一个独立的"镜头物理"决策。

### 7.1 镜头物理选择

不是**跳出表面**（从画面切换到另一视角），而是**穿进表面**（镜头物理推进到画面背后）。

```
正常内容流进行
    ↓
轮廓 + 内容一起放大 + 渐隐 ──┐
                          │ 镜头是"穿过玻璃"的感觉,
                          │ 不是"切到另一个画面"
                          ↓
              节点图浮现在深处
              （是表面背后的东西, 不是侧边栏视角）
                          ↓
节点图机制演完
    ↓
缩小 + 渐显回来 ─────────────┘
轮廓 + 内容回到原位, 流继续走
```

### 7.2 节点图本身的视觉

- 一行模糊的大剧情节点（横向排列）
- 从前一个节点延伸出多条不同曲线
- 曲线在中段发散开（千种可能）
- 最终再收束到下一个节点
- 然后继续延伸、再发散、再收束
- 反复几轮，呈现"导演不断在调度"的运作感

### 7.3 为什么选"穿过表面"

- **机制是表层之下的真相**（不是另一种视角）
- 投资人感受是 "我被允许看见了藏在背后的东西"，不是 "导演现在切换到工程视角讲解"
- 形式同构于母题 "**简单上瘾入口 + 深刻情感**"：表面简单（长按 + 上滑），深处复杂（导演 agent）

## 八、收尾：圆补全 + 散波 + slogan/logo

### 8.1 收尾分段

```
1. 星图铺满全屏 → 星图淡出, 角色显形           Beat 6 → Beat 7 过渡
2. 手机轮廓最后一次淡掉                       "去 UI 无界" 的视觉宣言
3. 角色形象在画面中央, 静止 (定格陪伴感)        "专属"落点
4. 弧顺着出现 → 补全成完整的"圆"               回响完成它的循环
5. 圆向外散波（像 demo 长按弧的涟漪）          名字 = 视觉
6. slogan + logo 落定在圆里 / 圆周围           收
```

### 8.2 时间预算

整段收尾 5-8 秒，是整片"最后呼吸"——**建议给它留出充分预算，不要被前面挤压**。

| 子段 | 估时 |
|---|---|
| 圆补全 | 1-2s |
| 散波 | 2-3s |
| slogan 浮现 | 1-2s |
| logo 落定 | 1s |

### 8.3 为什么这个结尾撑得住"专属"

- Act 3 = **广度 → 专属**
  - Beat 6 星图 = 广度（无数关系都在这）
  - Beat 7 收尾 = 专属（但这一颗、这一个他、这一段关系是她的）
- "弧补全成圆"在视觉上完成了：**单向的、未闭合的弧**（你说他听）→ **闭合的、完整的圆**（关系回响完整）
- 散波从"她的圆"向外扩散，但不接走任何东西——**护城河感**：东西在中央，世界向外看进来

## 九、VO 语言策略

### 9.1 强度

**轻语**——头一句、尾一句点题，中间让画面、操作、音效说话。

### 9.2 母语料（用户原话锁定）

> **"他的世界，你跟他的故事，由你一段一段推开，不断的惊喜，直至你们成为灵魂伴侣。"**

这段大白话本身就是一段三幕递进：

```
他的世界 / 你跟他的故事        ←  把"陪伴"重新定义（前奏 / 头 VO 的语义底）
由你一段一段推开                ←  Act 1 · 轻入口（上滑 = 你在推）
不断的惊喜                      ←  Act 2 · 深关系（AI 导演带来不可预测）
直至你们成为灵魂伴侣            ←  Act 3 · 资产化（终点, 宿命感）
```

VO 的头尾词稿在此基础上做剪裁。**示意（非最终词稿）**：

```
[片头·她还没开始]   "他的世界, 由你一段一段推开。"
[ ...90s 画面 ... ]
[片尾·她已走完]     "一段, 一段, 一段—— 直到你们成为灵魂伴侣。"
```

### 9.3 取向

- **第二人称代入式**（"你说的话，他真的听见了"这一类）
- **不要疑问式**（观众进入思考状态，分散沉浸感）
- **不要断言式**（观众进入被推销状态）
- **不要比喻式**（增加理解成本）

## 十、制作清单

按目前方案反推，制作素材分三类。

| 类别 | 项目 | 量级 |
|---|---|---|
| **demo 既有可用** | beat 1（钩子）、beat 4（回单屏）、beat 7 角色定格部分 | 现有 8 场剧本可剪 |
| **demo 需要扩建** | beat 2 三屏的 3 个不同响应、beat 5a/5b/5c 三个关系瞬间 | **4-6 段新 demo 内容** |
| **纯概念动画** | beat 3 AI 导演节点图、beat 6 星图、beat 7 圆补全 + 散波 | **3 段动画** |

**含义**：这片子的制作 ≠ 拍现有 demo，而是 **一次小型的 demo 路线图推进 + 三段概念动画**。这件事影响周期，制作启动前要心里有数。

## 十一、已否决 / 暂缓的方向

> 这些不是失败方案，是显性砍掉、留作判断依据。

| 方向 | 处理 | 理由 |
|---|---|---|
| **痛点对比**（蒙太奇打"今天的陪伴长什么样"） | 砍 | 不合整片气质——本片要的是自信、舒缓、宿命感，而非攻击性 |
| **"他有自己的时间线 / 会不在线"愿景点** | 不进本片 | 90s 太紧。留给后续投后/PPT/下一支片子展开 |
| **去屏幕化 / 跨硬件迁移**（手机→眼镜→音箱） | 不进本片 | 同上。本片专心讲 hero + 多形态 + 资产化 |
| **三屏背后的"三"= 三个用户/三种内容/三种假设** | 砍, 选定 = **同男主 + 三用户输入** | 同男主组合的"IP + 平台属性双效果"在 90s 内最直接 |
| **平台中性气质**（冷白抽象未来感） | 砍, 选定 = **继承 demo 气质**（暗色东方奇幻） | demo 素材直接可用、世界观连贯；投资人感知的是 "这家公司有完整审美" 而非 "通用工具" |
| **重 VO / manifesto 全片贯穿** | 砍, 选定 = **轻语头尾** | 母题已经被画面演出来了, VO 不需要再说一遍 |
