## 三、特效原则：避免写实粒子

> 用粒子模拟具象的"火/水/烟/血"会塑料感很重。粒子只用作**抽象光点 / 尘埃 / 体积光**——非具象指代物。具象的视觉冲击靠**整图素材 + 闪/震/明暗 ramp** 实现。

| 类别 | 当前 fx.js API | 走向 |
|---|---|---|
| ghost-fire 鬼火 | 蓝白点光粒子 | ✅ 保留（抽象光点） |
| dust 尘飘 | 抽象浮粒 | ✅ 保留 |
| moonbeam 月光柱 | 体积光柱 | ✅ 保留（光，非粒子模拟物） |
| sunbeam 阳光柱 | 粒子模拟阳光 | ⚠️ 已被 cj5 整图替代——不再被脚本调用，API 暂保留待清理 |
| bigFlameBurst 大火焰 | 粒子模拟火焰 | ⚠️ **改实现**——内部换为"整图（cj2）短暂叠加亮度 1.4 + flash" |
| risingFog 雾升腾 | 粒子云 | ⚠️ **改实现**——CSS 半透白板 + `mix-blend: screen` + opacity ramp |

> 改 fx.js 内部实现不动 API 签名，script.js 不需要改动。

## 四、配合愿景曲线的优先级

按 [节奏起伏.html](节奏起伏.html) 中"当前 vs 愿景"差距大小排优先级：

### P0 · 接入新分场（已落地）

cj1/2/3 整图 100% 高位问题——本轮通过"cj1 跨场 1/2/3 同源切换 + cj5 替代 cj3 + cj3 弃用"解决。覆盖率从全程 100% 拉到符合愿景的 25→45→85→…→100% 阶梯。

### P1 · 填满 0% 谷（场 4 中段）

场 4 改用 cj2 整图底 + 藤蔓 + 食人花叠加。允许 2 单体叠加（破例），让覆盖率从 0 → 50 → 75 → 0（救场清空）。

### P2 · fx.js 三个写实粒子改为非粒子实现

`bigFlameBurst` / `risingFog` / `sunbeam`——签名不变，内部换实现。

### P3 · 摸摸 4 阶演出补强（场 7）

立绘差异度不够，靠 emotion `flush-rose` 递进 + character-glow + 节奏停顿撑差异感。立绘换图反而是次要的。

### P4 · 假笑演出补强（场 8）

钩子点睛瞬间，靠 emotion 闪 + shake + 瞳孔急缩补。

### P5 · 训狗诗字符浮起特效（场 6）

视觉风格区分"画里的字"，长期投入。当前 `heavy` 占位可用。
