## 核心架构(一图速览)

```mermaid
flowchart LR
  subgraph N["叙事输入(AI 导演)"]
    A1["桥段<br/>起 / 承 / 转 / 合"]
    A2["张力<br/>低 / 中 / 高"]
  end
  A1 & A2 --> B["翻译表<br/>4 × 3 = 12 落点"]
  B --> C["覆盖率档位<br/>0 / 25 / 50 / 75 / 100"]
  C --> D["11 层视觉栈<br/>5 分组叠加"]
  D --> E["遮挡 + 让位<br/>+ 段切过渡"]
```

> **AI 导演**输出叙事语言(桥段 × 张力)→ **系统**按翻译表得视觉档位 → **11 层栈**按 5 分组叠出最终画面。

---

## 关键前提

Echo 推进 = 用户上滑驱动,**段落驻留时长不在系统控制中**。本规则集**不立**「留白 ≤ Xs / 静止 ≤ Xs」一类硬约束。系统只管「画面状态」+「段切过渡」,不管「停留多久」。
