## § 1 视觉层级 · 11 层视觉栈

从上到下的图层叠加(看到的最上面 → 最下面):

```
              ┌──────────────────────────────┐  ← 视觉最上
P0 表面层  ── │ ⑪ 交互 UI                    │
              │ ⑩ 交互特效(一闪 / 一震)     │
              │ ⑨ 文字层(旁白 / 对白)       │
              ├──────────────────────────────┤
P1 前景组  ── │ ⑧ 心境氛围(主角侧 染整画)   │
              │ ⑦ 前景主特效                 │
              │ ⑥ 场景前景(单体切图)        │
              ├──────────────────────────────┤
P2 角色    ── │ ⑤ 立绘                       │  ← 视觉中轴
              ├──────────────────────────────┤
P3 后景组  ── │ ④ 环境氛围(世界侧 染后景区) │
              │ ③ 后景主特效                 │
              │ ② 场景后景(整图遮罩或单体)  │
              ├──────────────────────────────┤
P4 底色    ── │ ① 极暗底                     │  ← 视觉最下
              └──────────────────────────────┘
```

## § 2 协作机制 · 一图说清

```mermaid
flowchart LR
  subgraph BE["后端"]
    direction TB
    BE1["阶段一 · 导演<br/>━━━━━━━━━━<br/>判断剧情要不要往前推<br/>如果要推,产出新场景:<br/>地点 / 整体氛围 / 角色心境"]
    BE2["阶段二 · 角色<br/>━━━━━━━━━━<br/>生成本轮的具体表演:<br/>台词 / 动作神态 / 回话选项"]
    BE1 --> BE2
  end

  subgraph MID["决策器(中介层)"]
    direction TB
    M1["后景组<br/>整体故事侧"]
    M2["前景组<br/>角色周遭侧"]
    M3["立绘<br/>角色本体"]
    M4["冲击<br/>瞬时镜头"]
  end

  subgraph FE["前端"]
    direction TB
    F1["大背景<br/>+ 环境氛围"]
    F2["角色周遭<br/>+ 情绪氛围"]
    F3["角色表情动作"]
    F4["瞬时镜头冲击"]
    F5["叠加成最终画面"]
    F1 --> F5
    F2 --> F5
    F3 --> F5
    F4 --> F5
  end

  BE1 --> M1
  BE1 --> M2
  BE2 --> M2
  BE2 --> M3
  BE2 --> M4

  M1 --> F1
  M2 --> F2
  M3 --> F3
  M4 --> F4
```

**三栏关系**:
- **后端**只产出"剧情走向 + 角色表演",不直接管画面长什么样
- **决策器**是中介:**有取舍地**从后端两阶段各取所需,翻译成前端各层要怎么变
- **前端**只负责按决策器给的指示更新画面,不操心剧情怎么走

## § 3 一段剧情内,每轮谁在变

下表展示一段剧情内 8 轮的典型时序——每一列是一轮,每一行是后端的一个角色或前端的一层。**只列了第一期实际会被决策器调度的 6 层**;其他层要么跟角色直出(⑪ 交互 UI / ⑨ 文字层)、要么第一期暂不做(⑥ 场景前景 / ⑦ 前景主特效)、要么永远在底(① 极暗底),本表不画。

| 角色 / 层 | 归属 | 轮 1 | 轮 2 | 轮 3 | 轮 4 | 轮 5 | 轮 6 | 轮 7 | 轮 8 → 切换 |
|---|---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 导演判断 | 后端 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| 导演产新场景 | 后端 | ★ |  |  |  |  |  |  | ★ |
| 角色表演 | 后端 | ● | ● | ● | ● | ● | ● | ● | ● |
| **⑩ 交互特效** | 冲击决策器 |  |  |  | ● |  |  | ● |  |
| **⑧ 心境氛围** | 前景组决策器 |  |  | ● |  |  |  | ● |  |
| **⑤ 角色立绘** | 立绘决策器 | ● | ● | ● | ━ | ● | ● | ● | ● |
| **④ 环境氛围** | 后景组决策器 | ● | ━ |  |  |  |  |  | ★ |
| **③ 后景主特效** | 后景组决策器 | ● | ━ |  |  |  | ● | ━ |  |
| **② 场景后景** | 后景组决策器 | ● | ━ | ━ | ━ | ● | ━ | ━ | ★ |

**图例**:`✓` 每轮都判 · `★` stage 切换瞬间产出 · `●` 这一轮**变化**(出现 / 切换 / 重置) · `━` 这一轮**保持**(显式占着,跟上一轮同状态) · 空 = 这一轮该层**不在场**

## § 4 四个决策器的运作原理

每个决策器接收什么输入、内部怎么判、输出给前端哪些层。

**图例**:🟦 = 来自**导演输出** · 🟩 = 来自**角色输出**

### 4.1 立绘决策器

```mermaid
flowchart LR
  subgraph IN["输入"]
    direction TB
    I1["角色输出:<br/>情绪 / 说话风格 /<br/>动作倾向 / 旁白描写 /<br/>视角暗示(靠近 / 远离)"]
    I2["导演输出:<br/>剧情进展 — 角色是否<br/>被带离画面"]
  end

  P1{"角色在不在场<br/>表情 / 动作切哪个<br/>位置 / 大小要不要调"}

  subgraph OUT["输出"]
    direction TB
    O1["⑤ 角色立绘<br/>在场 → 切表情 / 切动作 /<br/>          调位置 / 调大小<br/>不在场 → 退场 / 不画"]
  end

  I1 --> P1
  I2 --> P1
  P1 --> O1

  classDef director fill:#cfe2ff,stroke:#084298,color:#000
  classDef actor fill:#d1e7dd,stroke:#0f5132,color:#000
  class I2 director
  class I1 actor
```

### 4.2 前景组决策器(第一期只管 ⑧ 心境氛围)

```mermaid

  end

  I1 --> P1
  I2 --> P1
  P1 --> O1

  classDef director fill:#cfe2ff,stroke:#084298,color:#000
  classDef actor fill:#d1e7dd,stroke:#0f5132,color:#000

  class I2 actor
```

### 4.3 后景组决策器

```mermaid
flowchart LR
  subgraph IN["输入"]
    direction TB
    I1["导演输出:<br/>新场景(地点 / 氛围基调)/<br/>剧情节拍 — 当前段戏走到哪"]
    I2["角色输出:<br/>旁白远近 / 推拉 /<br/>视角变化暗示"]
  end

  P1{"是否切场景<br/>位置 / 大小是否调<br/>主特效是否进出"}

    O2["③ 后景主特效<br/>开 / 退 / 换种类 / 维持"]
    O3["④ 环境氛围<br/>切 / 退 / 维持"]
  end

  I1 --> P1
  I2 --> P1
  P1 --> O1
  P1 --> O2
  P1 --> O3

  classDef director fill:#cfe2ff,stroke:#084298,color:#000
  classDef actor fill:#d1e7dd,stroke:#0f5132,color:#000
  class I1 director
  class I2 actor
```

### 4.4 冲击决策器

```mermaid
flowchart LR
  subgraph IN["输入"]
    direction TB
    I1["角色输出:<br/>旁白 burst 词<br/>(猛然 / 一瞬 / 突然 / 撞)/<br/>动作倾向 — 近身动作<br/>(扣腕 / 拽 / 抱 / 撞)/<br/>情绪从一档跳到另一档<br/>(平静→愤怒 / 戏谑→撕碎)"]
  end

  P1{"是否到了冲击瞬间"}

  subgraph OUT["输出"]
    direction TB
    O1["⑩ 交互特效<br/>触发一次:屏震 / 一闪 / 推拉<br/>(触发完即消,不保持)<br/>多数轮次:不触发"]
  end

  I1 --> P1
  P1 --> O1

  classDef actor fill:#d1e7dd,stroke:#0f5132,color:#000
  class I1 actor
```
