# 素材展现 · 机制(规则手册)

> Echo 测试版素材展现规则集,4 维度 17 条子规则。供 PM 编排新场、程序按参数实现、AI 导演接入。
>
> 关联:[速览.md](素材展现-速览.md) | [工作笔记.md](素材展现-工作笔记.md) | [../01-通用设计规范/表现设计.md](../01-通用设计规范/表现设计.md)

---

## 关键前提

Echo 推进 = 用户上滑驱动,**段落驻留时长不在系统控制中**。系统能控的"时长"只有两类:

1. **段落内动效**(立绘呼吸 / 氛围 ramp / 特效漂移速度)
2. **段落切换过渡**(上滑触发后的画面渐变 / 转场时长)

任何「留白 ≤ Xs」「静止 ≤ Xs」类规则**不立**——驻留多久全凭用户行为。

## 1. 覆盖率 × 桥段

### 1.1 架构:叙事 / 视觉两层解耦

Echo 全链路有两套语言,**桥段 ≠ 档位**:

| 层 | 内容 | 产出方 | 例子 |
|---|---|---|---|
| **叙事语言**(质性) | 起承转合 + 张力 | AI 导演 / 剧本作者 | "这段是承在推进 / 张力中等" |
| **视觉语言**(量性) | 覆盖率档位 / 形状 / 中心点 / 尺寸 | 系统按规则翻译 | "档位 = 50, 中心 = (50,50)" |

AI 只输出叙事语言,系统负责"叙事 → 视觉"翻译。

### 1.2 桥段分类

**4 类枚举**,AI 导演必须从中四选一:

| 桥段 | 叙事作用 |
|---|---|
| **起** | 铺垫 / 引入,建立场域 |
| **承** | 推进 / 发展,信息累积 |
| **转** | 转折 / 高潮 / 冲击 |
| **合** | 收束 / 余韵 / 决意 |

**约束**:
- 段落级标签(40-80 字 / 5-10s 一段),不是场级——一场可由多个桥段构成
- 场内"回旋"(档位回落)通过覆盖率变化呈现,叙事仍是「承」,不增桥段
- 转场过渡是段落边界,不是桥段状态
- 4 类必须完整覆盖 + 不交叠

### 1.3 叙事 → 视觉 翻译表

AI 输出两个字段,系统按表查询:

| 桥段 \ 张力 | 低 | 中 | 高 |
|---|---|---|---|
| **起**(铺垫引入) | **0** | **25** | **50** |
| **承**(推进发展) | **25** | **50** | **75** |
| **转**(高潮转折) | **50** | **75** | **100** |
| **合**(收束余韵) | **25** | **50** | **75** |

读法:
- "桥段告诉系统**这段在做什么**"(铺垫 / 推进 / 冲击 / 收束)
- "张力告诉系统**做到什么程度**"(轻 / 用力)
- 4×3 = 12 落点覆盖 5 档,精确翻译

### 1.4 变化速率

档位变化遵循「段落级稳定 + 段落切换跳变」:

- **段落级稳定**:同一段落内档位保持不变——一个段落 = 一个画面状态
- **段落切换跳变**:切到下个段落时可任意跳变到任何档位
- **跨 ≥ 2 档过渡**:需 0.5-1s 渐变(如 25→75 / 0→75 / 50→100);跨 1 档可硬切
- **交互特效不算档位变化**:屏震 / 闪 / 镜头推拉等表面层瞬时行为叠加在当前档位之上,不改变档位本身

### 1.5 场景层结构 + 贡献口径

**场景层细化**(对 [`表现设计.md §一`](../01-通用设计规范/表现设计.md) 的补充):

| 槽位 | 允许的元素类型 |
|---|---|
| 场景·后景 | 背景图(整图遮罩)**或** 后景单体(切图)—— 二选一,互斥 |
| 场景·前景 | **只能是单体切图,不允许整图** |

**共存矩阵**:

| 组合 | 允许 |
|---|---|
| 后景图 ⇔ 后景单体 | ❌ 互斥 |
| 后景任意 ⇔ 前景单体 | ✅ |

**贡献覆盖率的口径**:

- 背景图:椭圆 / 直边遮罩面积百分比 = 档位值
- 场景单体:有自己的大小维度(见 §1.6)
- 氛围层 / 特效层:**不计入覆盖率**(只染色 / 叠加,不"占面积")

### 1.6 场景单体的大小 / 位置

**单体大小**:
- 产品参数 = 「目标占屏比例」,**连续值,10% - 50%**
- 测量口径:面积占屏比例(单体可见像素面积 / 屏幕面积)
- < 10% → 不画(美术不出此尺寸)
- > 50% → 该改成背景图(整图遮罩)

**单体数量上限**:
- 场景·后景 最多 1 个(且与后景图互斥)
- 场景·前景 最多 1 个
- → Echo 任意时刻**最多 2 个单体在场**(1 前景 + 1 后景)

**总覆盖率算法**:

> **档位 = 后景元素的覆盖率**(图遮罩面积 **或** 单体大小);前景单体不计入主档位(独立装饰)

**档位与单体的对应**:

| 档位 | 后景实现 |
|---|---|
| 0 | 后景空(纯极暗底) |
| 25 | 后景图椭圆 25% 或 后景单体 ~25% |
| 50 | 后景图椭圆 50% 或 后景单体 ~50%(临界) |
| 75 | **只能后景图椭圆 75%**(单体撑不起) |
| 100 | **只能后景图全揭** |

**单体位置**:
- 中心点 `(cx, cy) ∈ {25, 50, 75}²`,共 **9 个落点**
- 不用半框位(单体应完整可见,不允许"半飞出画面")
- AI 输出 `(单体 ID, cx, cy)`,系统按坐标渲染

## 2. 动效节奏

系统能控的两类时长:**段落内动效** + **段落切换过渡**。

### 2.A 段落内动效

#### 2.A.1 持续型动效 · 与张力联动

复用张力三档,映射到持续型动效速度:

| 张力 | 立绘呼吸 | 氛围 ramp | 主导特效漂移系数 | character-glow 律动 |
|---|---|---|---|---|
| **低** | 5s / 周期 | 1.2s | 0.5× | 5s / 周期 |
| **中** | 3s / 周期 | 0.8s | 1.0× | 3s / 周期 |
| **高** | 1.5s / 周期 | 0.4s | 1.8× | 1.5s / 周期 |

持续型动效速度由 AI 选定的张力档决定,AI 不单独指定速度。

#### 2.A.2 瞬时事件(burst) · 两层定位

burst **只发生在以下两层**:

| 层 | 语义侧 | burst 形式 |
|---|---|---|
| **⑧ 心境氛围** | 主角 / 角色侧 | emotion 色相瞬时染整画(red-alert / cold-shock 等) |
| **⑩ 交互特效** | 镜头 / 画面容器侧 | 纯瞬时全屏冲击(flash / shake / 镜头推拉 / 烈焰爆开 / 色彩失真) |

**剧情道具不在 burst 范畴**:由 AI 导演判断:
- 太具象、需要"画出来"的(灯笼、纸扎人)→ 走 **场景层(⑥/②)单体图**,作为该层 on/off 入场处理
- 抽象、靠氛围意象的(雾、火光、烟尘)→ 走 **主导特效(⑦/③)粒子**,作为该层 on/off 切换处理

这两种情况都按所在层的常规 alpha 入场 / 主导特效切换规则走,不计入"瞬时 burst"。

**边界**:
- 整图"一帧闪现":视觉语义归 ⑧ red-alert burst,实现可自由(纯色染 vs 借整图)
- 角色立绘"局部高光 / 瞳孔急缩":归 ⑤ 角色表情切换,**非 burst**
- ② / ⑥ / ⑤ / ⑨ / UI / ④ **不发生 burst**

#### 2.A.2.1 burst 触发权

**混合策略**:系统按规则自动触发,AI 可显式 override:

| 层 | 系统默认触发条件 | AI override |
|---|---|---|
| ⑩ 镜头冲击(flash / shake / 推拉) | 覆盖率档位跨度大时自动 shake | 可追加(`burst:flash`)或取消(`no-burst`) |
| ⑧ 心境染整画(red-alert / cold-shock) | 张力跨档(尤其低→高)时自动 emotion 闪一次 | 同上 |

设计意图:AI 导演专注「叙事 + 张力」,常见镜头 / 心境冲击系统按"档位跨度 / 张力跨度"自然涌出,不让 AI 表达背负过重。

#### 2.A.2.2 触发阈值 + 频次上限

| 触发条件 | 阈值 | 响应 |
|---|---|---|
| 覆盖率跳动 | 跨 ≥ 2 档 | ⑩ shake × 1 |
| 张力跳动 | 跨 ≥ 1 档 | ⑧ 心境闪 × 1 |
| 同一段默认自动 burst | ≤ 1 次 | AI override 不计入,可追加多次 |

#### 2.A.2.3 burst 时长档位

| 层 | 默认时长 | 极限 快 / 慢 |
|---|---|---|
| ⑩ 镜头(flash / shake / 推拉 / 烈焰) | 0.3s | 0.15s / 0.6s |
| ⑧ 心境闪(red-alert / cold-shock) | 0.5s | 0.3s / 0.8s |

设计意图:**冲击越"虚"时长越短,越"实"时长越长**。镜头冲击只要让人感知到"画面被打了一下"即可;心境闪要让人看清色调。

AI override 可显式指定时长(`burst:shake duration=0.5s`),不限于上表。

### 2.B 段落切换过渡

系统按"目标声明 vs 当前声明"自动判别变化幅度,**三档过渡**:

| 类别 | 触发场景 | 过渡方式 | 默认时长 |
|---|---|---|---|
| **微变** | 仅换氛围 / 加减单体 / 单体位置微调 | 同层 alpha / position ramp | **0.6s** |
| **中变** | 换遮罩(同源整图调露出)/ 调档位 / 换主导特效 | 场景层 mask ramp + 氛围跟切 | **1.5s** |
| **大变** | 异源切场(整画底图源变了) | 旧画淡出 → 极暗底 → 新画淡入(三段式) | **3.0s** |

- 设计意图:Echo 偏沉浸而非节奏紧凑,过渡走"舒缓沉浸"基线
- **自动判别**:系统按"画面声明 DSL 的 diff 范围"自动归类
- AI 可显式 override 类别(`transition: micro/medium/large`)或时长(`duration: 1.2s`)

## 3. 层级协同

按 [`表现设计.md §一`](../01-通用设计规范/表现设计.md) 图层栈分 **5 组**。本章管「**遮挡优先级 + 让位机制**」,**不管注意力优先级**(后者由 §1 覆盖率 + §2 动效节奏管)。

### 3.1 五分组速查

| 分组 | 含层 | 语义侧 | 关键性质 |
|---|---|---|---|
| **P0 表面层** | ⑪ 交互 UI / ⑩ 交互特效 / ⑨ 文字 | 镜头 / 玩家侧 | 独立显示,不向下覆盖,永远顶 |
| **P1 前景组** | ⑧ 心境氛围(组顶染整画) / ⑦ 前景主特效 / ⑥ 场景前景 | 主角侧 | 在角色之前,与后景组形成双族镜像 |
| **P2 角色** | ⑤ 立绘 | 角色本体 | 视觉中轴,永远清晰可读 |
| **P3 后景组** | ④ 环境氛围(组顶染后景区) / ③ 后景主特效 / ② 场景后景 | 世界 / 场景侧 | 在角色之后 |
| **P4 底色** | ① 极暗底 | — | 永远在底,几乎不变 |

同组内顺序固定按图层栈编号(组顶 → 组中 → 组底)。跨组遮挡严格按 P0 → P4。

### 3.2 显式硬约束

- **主导特效**:任意时刻 1 种,⑦ / ③ 二选一(不同时);**默认全屏散布**,不引入"局部范围"概念——局部点状的视觉需求走场景层 ②/⑥ 单体切图
- **场景层**:⑥ / ② 各 0-1 个,双族可同时存在
- **氛围层**:⑧ / ④ **长开二选一**(任意时刻只一种长开在场),由剧情主线决定——外部场所为主走 ④,内心情绪为主走 ⑧;⑧ burst 短闪(0.5s)不占长开槽位
- **交互特效**:⑩ 不占槽位,可任意叠加

### 3.3 染色统帅作用域

| 层 | 染色范围 |
|---|---|
| ⑧ 心境氛围 | P1 自顶向下 + ⑤ + P3 + P4 = **整画** |
| ④ 环境氛围 | P3 自顶向下 + P4 = **后景区** |
| ⑩ 交互特效(burst) | 瞬间(0.3s 内)**压所有下层**(含 ⑨ 文字) |

### 3.4 让位机制

| # | 触发场景 | 让位动作 |
|---|---|---|
| 1 | 文字段 ≥ 60 字(密集段) | ⑧ / ④ 氛围 alpha **临时降 15-20%** 保文字可读,文字结束恢复 |
| 2 | ⑩ 镜头 burst 瞬间 | 0.3s 内所有下层被压(⑨ 文字也可被白闪 / 震失焦);冲击结束立即恢复 |
| 3 | 主导特效切换(⑦ ↔ ③ 或同侧换种类) | 旧淡出 → 极暗 → 新淡入,不允许两种叠加 |

**入场顺序不在本章立** —— 每段画面有哪些层在场、什么时机入场,**由 AI 导演按剧本需求决定**。系统只保证「同时在场时」的遮挡 + 让位按本章规则执行。

## 4. 露出区域

整图通过遮罩局部露出。**形状 + 羽化 + 中心点 + 尺寸**四要素决定一个露出区域的全部参数。

### 4.1 形状

| 形状 | 判定 | 适用 |
|---|---|---|
| **正圆**(默认) | `rx = ry`,单参数 `r` | 默认形状,窥探感最对称 |
| **椭圆** | `rx ≠ ry`(**任何偏差**) | 必须显式声明 + 附剧情语义 |
| **直边线性**(上 / 下 / 左 / 右半区) | 形状非圆族 | 强冲击 / 规整切割,预留 |
| **不规则** | – | 测试版不考虑 |

**判定严格化**:`rx ≠ ry` 一律视为椭圆,**没有"近似正圆"的灰色地带**。`28×26`(差异 7%)按新规则也是椭圆——要么归一为正圆(`27×27`),要么补剧情语义。

### 4.2 羽化

- **单档**:柔边宽度 = `短半径 × 20%`(全部圆 / 椭圆露出共用此档)
- **窥探感由羽化承担**——这是「望远镜 / 钥匙孔」感的来源,不是图层堆栈做的
- **无羽化的两种情况**:
  - 全揭 100% → 整图直出,无窥探框
  - 直边线性遮罩 → 规整切割,无朦胧带
- **不分浅 / 中 / 深档**:窥探强弱不通过羽化表达;由「尺寸档位 + 中心点偏移」承担,羽化只负责"是不是带柔边"这一个开关

### 4.3 中心点

- **含义**:遮罩(窥探框)中心点在画面上的坐标位置。坐标系:画面左上 `(0%, 0%)` → 右下 `(100%, 100%)`,默认中央 `(50%, 50%)`
- **档位**:`cx` 与 `cy` 各 5 档 → `{0, 25, 50, 75, 100}`
- **合法落点 13 个**:9 个常规(cx, cy ∈ {25, 50, 75})+ 4 个半框
- **半框约束**:`0` 或 `100` **仅允许出现在一个轴**上,另一轴必须为 `50`——避免"角上半框"(如 `(0, 0)`)的难读组合
- **偏移必须有剧情语义**——不为构图变化而变化

**13 个合法落点 / 语义分布**:

| 类型 | 落点 | 视觉效果 | 候选语义 |
|---|---|---|---|
| 默认 | `(50, 50)` | 完整窥探框居中 | 默认中性 |
| 常规偏 | `(25, 50) / (75, 50) / (50, 25)` | 完整窥探框偏向四方 | 待样本 |
| 常规偏 | `(50, 75)` | 完整窥探框下移 | 上岸视角(已用) |
| 常规角 | `(25,25) / (25,75) / (75,25) / (75,75)` | 完整窥探框偏向四角 | 待样本 |
| 半框 | `(0, 50)` | 右半框露出 | 从左侧探入 |
| 半框 | `(100, 50)` | 左半框露出 | 从右侧探入 |
| 半框 | `(50, 0)` | 下半框露出 | 从顶部下压 |
| 半框 | `(50, 100)` | 上半框露出 | 从底部探出 |

半框 4 个落点是「探入 / 探出」类语义的预留——值得后续场刻意触发,验证演出效果。

### 4.4 尺寸档位

**5 档**:与中心点档位完全对齐,共用 `{0, 25, 50, 75, 100}`。

| 档位 | 数值 | 含义 |
|---|---|---|
| **0** | 0% | 无窥探 / 留白(等价于场景后景未设入) |
| **25** | 25% | 铺垫期小窥探 |
| **50** | 50% | 推进期中窥探 |
| **75** | 75% | 推进峰大窥探(仍带羽化) |
| **100** | 100% | 整图全揭(**无遮罩、无羽化**) |

**规则**:
- 新场定义时**只能选档位**;中间值四舍五入到最近档位
- 「100」≠ 单纯百分比阈值,而是**形态切换**——整图直出、无遮罩、无羽化
- 跨档跳变 = 节奏冲击,需有剧情对应
- 与 §1 桥段档位对齐(铺垫 ~25 / 推进 ~50 / 推进峰 ~75 / 高潮 100)
- 与中心点档位共用 `{0, 25, 50, 75, 100}`——PM 不用记两套数

## 附:单体位置 vs 中心点档位的统一关系

同一套 `{0, 25, 50, 75, 100}` 坐标库被两个对象复用:

- **背景图中心点**:13 个合法落点(9 常规 + 4 半框)
- **单体位置**:9 个合法落点(只常规,不半框)

中心点的"半框语义"对应窥探视角(钥匙孔从外探入),对单体不适用,所以子集化。PM / 程序仍只需记一套坐标库。
