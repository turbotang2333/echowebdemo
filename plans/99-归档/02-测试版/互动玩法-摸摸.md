# 测试版 · 互动玩法 · 摸摸

> 测试版 第 7 场景"晨光讨好"段的亲密点玩法。通用接入约束见 [交互设计 · 二 互动玩法接入原则](../01-通用设计规范/交互设计.md)。

---

## 玩法规则

| 维度 | 内容 |
|---|---|
| **出现节点** | 第 7 场景的亲密点 |
| **操作** | 手指在立绘上**持续移动**抚摸(不是单点点击) |
| **正反馈** | 立绘局部反应、轨迹光痕、敏感区命中 |
| **失败回退** | 松开 = 进度回退 30%;2 秒内手指回来继续算原进度;超过 2 秒彻底失败 |

## 阶段推进(4 阶)

每阶段对应不同立绘 + 心境氛围补强(本场素材立绘差异度低,见 [素材清单.md](素材清单.md)):

| 进度 | 立绘 | 心境氛围 | 节奏 |
|---|---|---|---|
| 0-25% | `感觉有人在动的惊讶.webp` | 无 | 停顿 |
| 25-50% | `感觉被摸到的震惊.webp` | 无 | 停顿 |
| 50-75% | `一直被摸的脸红.webp` | `flush-rose` 浅 | 停顿 |
| 75-100% | `摸到最轻松的微笑.webp` | `flush-rose` 加深 | 慢推 |
| 100% 收束 | (闭眼笑) | 退,让 `dawn-warm` 接管 | 收束 |

> 立绘差异度低 → 主要靠心境氛围 `flush-rose` + 节奏停顿 + character-glow 撑梯度。详见 [表现设计 · 三.4 立绘差异度低时的协作模式](../01-通用设计规范/表现设计.md)。

## 进入 / 退出体感

按通用规范的「互动玩法接入原则」:

- **进入**:亲密点触发时,基础推进圆弧淡出 → 立绘可被手指触碰 → 用户立刻感知"进入玩法模式"
- **安全沙盒**:在玩法模式内,触摸、停顿、来回滑、放手再继续都不会切场景;整个画面是"安全"的
- **退出**:完成 100% 或彻底失败后,圆弧浮回 → 用户感知"回到主流程"
