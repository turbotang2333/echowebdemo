## 1. 设计来由 + 演化

### 1.1 为什么不立"时长硬约束"

最初想立「留白连续 ≤ 3s / 单素材静止 ≤ 15s / 单段 5-10s」这类硬约束,中途意识到:

> **Echo 推进 = 用户上滑驱动**。每段旁白出现后,用户不上滑就一直停留。段落呈现时长 = 用户行为决定,**不在系统控制中**。

所以前提全不成立。修订后:
- 删除"留白连续上限"子规则
- 把"时间节奏"维度改名为"动效节奏",只立**系统能控的两类时长**:段落内动效速度 + 段落切换过渡

### 1.2 为什么 burst 只两层(⑧⑩)而不是三层

中途版本曾把 burst 扩到三层(加 ④ 环境物件 on/off,如灯笼、纸扎人入场),后续撤回。用户原话:

> 不存在"道具"这个概念。除了前景和后景以外,前景后景的特效包含粒子模拟的下雨、雾气、火光等等。灯笼、纸扎人这种太具象的内容不需要画出来,**由导演机制判断**——生成一张单体图,还是交给粒子特效营造氛围。

修订后:
- burst 只两层(⑧ 心境 / ⑩ 镜头)
- 剧情道具的具象 vs 抽象选择交给 AI 导演,走"场景层单体图 on/off"或"主导特效 on/off",**不算 burst**

### 1.3 为什么不立"入场顺序"

中途版本曾尝试为段落切换定义出场顺序(底色 → 后景 → 角色 → 前景 → 表面),后撤回。用户原话:

> 入场根据导演剧本需求来定,设置一个出场顺序的意义是什么没理解。

修订后:
- §3 层级协同只管「同时在场时的遮挡 + 让位」
- 入场时机交给 AI 导演

### 1.4 为什么文字段密集时降的是氛围 alpha 而不是立绘 contrast / 文字 alpha

中途版本曾立"立绘 contrast 锁定 + 文字 alpha 让位"两条让位规则,后撤回。用户原话:

> 文字层永远高于前后景的特效层,不存在文字 alpha 让位问题;立绘 contrast 锁定没有必要。

修订后:让位机制只剩 3 条(氛围降透明 / 镜头压所有 / 主导特效切换淡入淡出)。

### 1.5 为什么"交互特效"的命名是镜头 / 画面容器侧

中途讨论"交互特效"层(⑩)究竟代表什么时,用户的概括:

> 交互特效控制整个屏幕晃动、闪等等效果。

最终定位为**镜头 / 画面容器侧** —— 与"⑧ 心境氛围 = 主角侧"形成两层镜像。屏震、白闪、镜头推拉是"打在画面容器上"的冲击,不属于场景或角色内部。

### 1.6 氛围层互斥规则的演化

最初版本:⑧ / ④ **可同时存在**(各染各的范围)。后修订为「**长开互斥,瞬时不算**」。

理由:用户原话——「氛围层不应该二者同时存在,只能二选一,根据剧情来去做判断」。

**边界澄清**:
- "长开" = 占用一段时间常驻染色(整段或半段),如场 1-3 全程 ④ `dark-water`
- "瞬时" = ⑧ burst 0.5s 一闪(red-alert / cold-shock),不属"在场长开"
- 8 场样本核对:全部符合"长开 ④ 或 长开 ⑧ 二选一,⑧ burst 可叠在 ④ 长开之上"
  - 场 1-3 / 5 / 6 / 7 / 8:长开 ④,⑧ 仅在情绪冲击点闪
  - 场 4:长开 ⑧ `red-alert`(救场),无 ④ 长开(env=-)

**剧情主线判断**:外部场所为主 → 走 ④;内心情绪为主 → 走 ⑧。

**实现层面**:⑧ / ④ 各自仍有独立的 alpha / 染色实现,但 PM 编排时需保证「同时刻不出现两个长开 emotion」。

### 1.7 主特效范围规则:全屏默认

最初未明文规定。补充明示规则:**主特效默认全屏散布,不引入局部范围概念**。

理由:用户原话——「特效的呈现范围、位置等等,这里没有讨论」。给出三个候选方案(全屏默认 / 复用露出区域参数 / 全屏+上下半屏)后,用户选 **A 全屏默认**。

**合理性**:
- fx.js 现状全部全屏(`ghost-fire` / `moonbeam` / `dust` / `rising-fog`)
- 主特效定位是「场域氛围」,不是「点状贴图」
- 局部点状需求(灯笼、纸扎人)走场景层 ②/⑥ 单体切图,职责分离

**未来扩展**:如果出现"火焰只在画面右下"这类需求,再扩 §3.2 加"局部范围"参数;当前测试版不需要。

## 2. 已否决项(避免重蹈)

| 否决项 | 原版方案 | 否决理由 |
|---|---|---|
| 留白连续上限 | "留白 ≤ 3s 否则觉得断片" | Echo 上滑驱动,段落驻留时长不在系统控制中 |
| 单素材静止上限 | "立绘 / 后景 静止 ≤ 15s" | 同上 |
| 单段时长上限 | "段落 5-10s" | 估算阅读时长,不是强制时长 |
| burst 第三层(④ 环境物件) | 灯笼 / 纸扎人 / 雾 / 火光归入 ④ on/off burst | 不存在"道具"概念,交给 AI 导演选择走场景层单体 or 主导特效粒子 |
| 段落切换出场顺序 | 强制底色→后景→角色→前景顺序 | 出场顺序由 AI 导演按剧本决定 |
| 让位规则 · 立绘 contrast 锁定 | 文字密集时立绘 contrast 暂定值 | 不必要 |
| 让位规则 · 文字 alpha 降低 | 镜头 burst 时文字 alpha 降低 | 文字永远在 ⑨ 层,高于特效层,无让位问题 |
| 椭圆 "近似正圆" 灰色地带 | rx/ry 差异 < 7% 视同正圆 | 严格化:任何 rx ≠ ry 视为椭圆,需附剧情语义 |
| 严格氛围互斥(瞬时也算) | ⑧ burst 时 ④ 必须先退场 | 与 8 场样本不符——场 2 / 5 / 6 / 7 / 8 多场是 ④ 长开 + ⑧ 瞬时闪。改为「长开互斥 + 瞬时不算」 |

### 3.1 三类观察

**显性约定(8 场已对齐,属现行规则)**
- 探索期覆盖率压在 25-35%(场 1-3 / 场 5 起 / 场 6 起 / 场 7 起)
- 高潮才推到 100%(场 5 / 8 全揭、场 2 闪现)
- 心境氛围**只在情绪冲击点短时出现**,不长开
- 环境氛围全程在场(场 4 是唯一例外——靠主导特效 ghost-fire 替代 env 撑场)
- 单场单一主导特效(场 4 鬼火 / 场 5 尘 / 场 6 月光柱),互不冲突
- 整图闪现 < 0.5s(场 2 cj2)是统一约定

**隐性飘移(各场不一,已被规则吸收)**
- 椭圆中心点:8 场里只有场 3 显式偏移 cy:75,其他场默认 50 → 已被 §4.3 中心点规则吸收
- 椭圆尺寸 13 个零散值 → 已被 §4.4 5 档位规则吸收
- 单体位置语义(鱼尾屏底偏右 / 藤蔓屏底+屏顶 / 食人花顶部下压)→ 4 类语义待后续完善
- 场时长跨度 50s → 150s,无单场时长上限规则 → Echo 上滑前提下无此规则
- 主导特效不是每场都有(场 1 / 2 / 3 / 7 / 8 缺)→ 主导特效是否应每场必有?**待讨论**

**真随机(暴露问题点)**
- `red-alert` 心境氛围在场 2(危险撕碎)/ 场 4(烈焰救场)/ 场 5(低吼一闪)/ 场 6(偷看羊人)各表达不同情绪——**同一预设承载 4 种情绪**,可能预设饱和度不够
- 场 4 完全跳脱「椭圆 reveal」范式,无整图、靠单体叠加 + 粒子主导——是「无整图模式」还是单点特例?见 §4 模式 C

## 4. 模式候选

从 8 场样本里能抽出 4 类范式。**识别方法**:同一组参数模式在 ≥ 2 场出现 = 一类范式;只出现 1 次 = "一次性",不入库。

| 模式 | 适用桥段 | 关键参数 | 样本场 |
|---|---|---|---|
| **A · 同源椭圆三阶段渐推** | 一组关联剧情(同一空间不同角度) | 同一张整图 × 椭圆参数 3 段渐变(S / M / L 档跨度) | 场 1 / 2 / 3 共用 cj1(28×26 → 32×28 → 50×22 cy:75) |
| **B · 整图闪现冲击** | 高潮瞬间的情绪冲击点 | 异源整图 × 0.3-0.5s × 100% × 心境氛围爆闪 | 场 2 cj2(全剧仅此一例,待第 2 场观察是否复用) |
| **C · 无整图 · 主导特效+单体叠加** | 无明确"地点"的过渡场 / 心理场 | 极暗底 + 主导特效粒子 + 0-2 个单体 | 场 4 火林(单例) |
| **D · 单图椭圆扩张到全揭** | 单场内推进到高潮 | 单整图 × 椭圆从 M 档扩到 Full 档 | 场 5(33→60→100)/ 场 8(44→78→100) |

**未入库 / 待样本**:
- 场 6「椭圆回旋式」(30 → 89 → 31 → ...)——目前仅 1 例
- 场 7「氛围切换主导式」(立绘弱差分,靠 emotion 切换撑节奏)——目前仅 1 例,但与通用规范 `表现设计.md §3.4` 的"立绘差异度低协作模式"对接,后续值得作为独立范式

每个模式的**完整描述**(各层职责 / 节奏骨架 / 参数范围)留到下一轮一起填——本稿先把候选名和样本场固定。

## 5. 可测试改动点

每条挂回某个维度问题,在 demo 上小范围跑实验。每条按 `改什么 / 假设 / 观察什么 / 回答哪个维度` 四字段。

### 改动 1 · 覆盖率档位归一

- **改什么**:把现有 13 个零散椭圆值四舍五入到 5 档(S25 / M35 / L50 / XL75 / Full100)
- **假设**:档位化不影响观感,且让节奏更清晰
- **观察什么**:8 场连播下来,节奏感是否依然成立?有没有某场因为档位调整变得不对劲?
- **回答维度**:1 覆盖率 / 4.4 尺寸档位

### 改动 2 · 文字段让位机制

- **改什么**:场 5 焦土(文字密集段)期间,环境氛围 `scorched` alpha 临时降 15%
- **假设**:文字读得更清且不破坏氛围感
- **观察什么**:文字阅读舒适度 / 场域基调是否被削弱
- **回答维度**:3.4 让位机制

### 改动 3 · 露出中心偏移语义

- **改什么**:场 7 晨光场,椭圆中心从 `cy=50%` 上移到 `cy=40%`,对齐角色头部
- **假设**:中心点跟随角色 = "焦点在他",是一个通用偏移语义
- **观察什么**:亲密点是否更聚焦?观感是否改善?
- **回答维度**:4.3 中心点偏移语义

### 改动 4 · burst 阈值校验

- **改什么**:场 6(30→89)跨 ≥ 2 档,按规则自动触发 ⑩ shake;场 7(51→60)跨 1 档,不触发
- **假设**:阈值与现有手写演出一致
- **观察什么**:连播观感无突兀
- **回答维度**:2.A.2.2 触发阈值
