# 场景效果排查表 (v2)

> 用途：把 [demo-script.md](demo-script.md) 每一拍按"内容 + 视效"拆成独立列，方便横向扫读、做调整。
>
> **列说明（每行 = 剧本中的一拍）**：
> - **#**：拍号
> - **角色台词**：他/狐狸说的话
> - **用户台词**：圆弧节点用户说的话
> - **旁白**：第三人称叙述（含 inner 内心 OS / aside 小字旁注 / heavy 重旁白 / npc 缺席旁白，类型用 `(类型)` 标注）
> - **立绘**：本拍的位置（pos）/姿态（pose）/可见性变化
> - **场景效果**：背景图、底色、氛围、镜头运动、环境变化
> - **特效**：粒子/震屏/光柱/闪光等程序化 fx
> - **用户操作**：本拍要求用户做什么动作（自动 / 上滑·轻 / 上滑·切场 / 长按 / 点按 / 摸摸）
> - **实现状态**：✅ 已对齐 / ⚠️ 部分实现 / 🔴 未实现 / — 不适用
>
> **空格代表本拍此项无内容**。
>
> 当前 v2 已实现的特效种类（fx.kind）：`shake / flash / ghost-fire / flame-burst / fog-on/off / dust / moonbeam / rising-fog / lanterns-on/off / nail-people-on/off / character-glow / endmark`。表里凡是不在此列表的特效都是 🔴。
