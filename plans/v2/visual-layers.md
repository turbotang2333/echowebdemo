# v2 视觉层级设计

> 关联：[demo-flow.md](demo-flow.md)、[demo-script.md](demo-script.md)、[art-assets.md](art-assets.md)
> 本文档定义 v2 的视觉层级架构。**核心原则：单元素**——除角色与交互 UI 外，三大层在任意时刻各只呈现 1 种元素，确保画面不混乱、留白即想象空间。

## 一、最终层级（自下而上）

```
┌──────────────────────────────────────────┐
│ ⑨ 文字层（旁白/对白/inner/aside）       │ ← paragraph 已有
├──────────────────────────────────────────┤
│ ⑧ 交互 UI 层（圆弧/手势 tip）           │ ← ring / swipeTip 已有
├──────────────────────────────────────────┤
│ ⑦ 特效·伴随（屏震/闪/推拉，瞬时）       │ ★ 单元素原则之外
├──────────────────────────────────────────┤
│ ⑥ 特效·主导（粒子/光柱/训狗字符浮起）   │ ★ 单元素原则
├──────────────────────────────────────────┤
│ ⑤ 氛围层 · 心理（emotion mode）          │ ★ 角色之上，染整张画面
├──────────────────────────────────────────┤
│ ④ 角色层                                  │ ← character 已有
├──────────────────────────────────────────┤
│ ③ 氛围层 · 环境（env mode）              │ ★ 角色之下，只染场景
├──────────────────────────────────────────┤
│ ② 场景层                                  │ ★ 单元素原则
├──────────────────────────────────────────┤
│ ① 极暗底（纯黑/纯深色）                   │ ← bgColor
└──────────────────────────────────────────┘
```

**单元素原则（最关键）**：

- 场景层：任意时刻只 1 种元素（无论来源是 PNG 切图还是整图露出）
- 氛围层：任意时刻只 1 种氛围（要么 env 在底，要么 emotion 在上，**不同时存在**）
- 特效·主导：任意时刻只 1 种主导特效

**层级位置说明**：

- **氛围层有两个可能的挂载位**——env 模式挂在角色之下（只染场景），emotion 模式挂在角色之上（染整张画面包括角色）。**任意时刻只有一个挂载位是激活的**，另一个处于空状态。这是"同一套氛围参数 + 两个 z-position 选项"的设计。
- **特效·主导在两个氛围层之上**——粒子（鬼火、月光柱、晨光柱）保持自身色相不被氛围二次染色。
- **角色层在场景之上**——常规堆叠。
- **交互 UI 与文字在最上**——任何视觉变化都不应该挡住玩家在读什么、能点什么。

## 二、场景层（单元素原则）

### 2.1 核心定义

**场景层 = 任意时刻画面中那 1 个明确的可识别元素**。覆盖率沿用你的设计：20-30% / 50-60% / 100%。

**剧情决定需要哪些单体元素**。每个单体的素材来源有两条平行路线：

| 素材路线 | 含义 |
|---|---|
| **PNG 切图** | 一张干净的透明 PNG（鱼尾、藤蔓、食人花…），整张图就是一个单体 |
| **整图局部露出** | 整张场景图（骸骨、宅院…）中露出某一块区域，**这块区域 = 一个单体**，剧情不需要的部分被遮住 |

> **关键认知**：两条路线**并列等价**，不是"切图优先 / 整图代用"。
> 场景需要 N 个单体，**单体可以是从整图中切出的局部**。当切图来不及做时，给一张整图，按需露出局部 = 用上其中的某个单体。
> 一张整图可以承载多个单体（露出不同区域 = 不同单体），切换时 = 单体切换。

### 2.2 不混搭

**整图与切图不在同一画面共存**。即：

- 一个场景如果以整图为单体来源 → 整场都从这张整图露出不同局部
- 一个场景如果以切图为单体来源 → 整场都用切图增减
- **不会出现**"整图 + 上面叠一张切图"的混搭——这会让画面信息源不单一

### 2.3 单元素切换

- **同源切换**（同一张整图露出不同区域 / 切换到该整图的下一个单体）：旧露出区域**渐变扩大、缩小或位移**到新区域
- **异源切换**（换成另一张图的单体）：旧元素淡出 → 极暗底瞬间 → 新元素淡入。中间允许有一拍纯黑，强化"画面切换"的力度

### 2.4 整图露出的遮罩形状

整图永远以 cover 方式 100% 铺，露出靠**遮罩**控制：遮罩内是图，遮罩外是极暗底。

**默认形状**：椭圆遮罩

- 中心 `(cx, cy)`、半径 `(rx, ry)`、柔边宽度

**线性遮罩**（部分场景使用）：

- **上半区**：露出图的上半部分（例如只露出"远处天空+山影"）
- **下半区**：露出图的下半部分（例如只露出"地面+焦土"）
- **左/右半区**：横向半分

> **单体认知保留**：无论椭圆还是线性，露出区域内的内容应该构成"一个可识别的单体"，而不是"一张被裁了一半的图"——遮罩位置由剧情想要呈现哪个单体决定。

### 2.5 场景层留白

被压暗 / 不在露出区域 / 没有切图覆盖的部分，全部交给极暗底。**留白本身是设计**——给玩家想象空间。

## 三、角色层

不变。延续现有 character.js 的位置/姿态系统。

**唯一约束**：角色层不参与场景层的"覆盖率计算"。即：场景覆盖率指的是场景层占画面的比例，角色不计入。

## 四、氛围层（单氛围原则 · 双挂载位 · 新增）

### 4.1 设计目标

> **一套氛围参数系统服务两种用途**：场景的光线/时间/天气感受、角色的心理感受。**同一时刻只激活其中一种**。

| 模式 | 表达 | 挂载位 | 染色范围 |
|---|---|---|---|
| **env** | 环境氛围：明暗、时间、天气、地点性 | 角色之下 | 只染场景层 |
| **emotion** | 心理氛围：愤怒、恐惧、亲密、冷漠 | 角色之上 | 染整张画面（场景 + 角色 + 一切） |

**为什么分两个挂载位**：

- env 在底意味着角色色调始终保持自身（不会因为场景变冷蓝就让角色脸也变蓝），**保护角色视觉一致性**
- emotion 在顶意味着情绪一变整张画面（含角色）一起变，**让心理冲击成为整体感受**
- "美好晨光下心境忽然变冷"这种反差 = env(`dawn-warm`) + 切到 emotion(`cold-shock`) 一闪——env 仍在底维持环境，emotion 在顶覆盖整张画面给冲击

### 4.2 控制参数

env 与 emotion 共用同一组参数。区别只在挂载位：

| 参数 | 范围 | 作用 |
|---|---|---|
| `tint` | hsl 色 | 主色相 |
| `tint-strength` | 0-1 | 染色浓度 |
| `brightness` | 0-1.5 | 整体亮度 |
| `contrast` | 0.6-1.6 | 对比度 |
| `vignette` | 0-1 | 四角暗化强度 |

实现层面：env 与 emotion 各占一个 DOM 容器（`.atmo-env` / `.atmo-emotion`），分别挂在角色之下与之上。同一时刻只一个容器有内容，另一个 opacity:0。`mix-blend-mode` 配合参数动画过渡（300-1500ms）。

### 4.3 氛围预设

预设以名字调用，beat 级声明切换。预设携带"建议挂载位"，但 beat 也可显式覆盖。

| Preset | 建议模式 | tint | brightness | vignette | 用途 |
|---|---|---|---|---|---|
| `dark-water` | env | 深蓝 | 0.3 | 0.4 | 场景 1 黑暗水中 |
| `cold-blue` | env | 冷蓝 | 0.4 | 0.3 | 场景 4 火林 / 场景 6 月夜洞穴 |
| `flame-warm` | env | 暖橙 | 0.9 | 0.1 | 场景 4 烈焰救场 |
| `scorched` | env | 灰红 | 0.7 | 0.3 | 场景 5 焦土 |
| `dawn-warm` | env | 暖橙黄 | 1.0 | 0 | 场景 7 晨光 |
| `fog-mansion` | env | 灰白偏冷 | 0.6 | 0.4 | 场景 8 钩子宅院 |
| `flush-rose` | emotion | 暖粉 | 0.95 | 0 | 摸摸 50-100% 脸红到放松 |
| `cold-shock` | emotion | 金红一闪 | 0.8 | 0.2 | 钩子瞳缩瞬间 |
| `red-alert` | emotion | 全屏红 | 0.7 | 0.5 | 危险/愤怒瞬间 |

> 预设清单不是封闭的，剧本推进时可以新增。

### 4.4 氛围切换规则

- **场景切换 beat** → env 渐变到新场景的默认预设（500-1000ms）；emotion 重置为空
- **段落推进** → 默认不变。剧情明确需要时可切（例如摸摸 4 阶就是 4 次氛围切换）
- **emotion 入场时 env 不退**——env 维持环境基调，emotion 在角色上方加一层情绪冲击。两者**视觉上叠加**，但**单元素原则在每个挂载位内分别成立**：env 同时只 1 个，emotion 同时只 1 个

### 4.5 与立绘差异度低的协作

立绘资产（如摸摸 4 张几乎同姿态）差异度不够时，**emotion 氛围切换是补强主力**：

```
摸摸 0% → 25% → 50% → 75% → 100%
env:     dawn-warm（不动）
emotion: 无 → 无 → flush-rose浅 → flush-rose → 无（让 dawn-warm 的暖白接管）
立绘:    原图  原图  脸红切图     脸红切图   闭眼笑切图
特效:    摸摸轨迹光痕（粒子，常驻）
```

立绘单看几乎不变，但**配合 emotion 递进 + 特效**，体验上有清晰梯度。

## 五、特效层（单主导原则）

### 5.1 哲学：克制 + 抽象

> 前端直接画的写实细节几乎一定廉价。能用粒子、光、震动表达的，就不画 SVG 物件。

**允许 ✅**：
- 抽象粒子：鬼火、尘、雾、雨、火星、水滴、血粒、训狗字符浮起
- 全屏动态：屏震、白闪、缩放推拉、镜头平移、聚焦模糊
- 短促色彩失真

**禁止 ❌**：
- 在角色身体上画 SVG 元素（手腕画绳子、嘴角描红线、头顶画爱心）—— 一画就廉价
- 写实物件 SVG（杯子、果子、骨头）—— 用切图，归到场景层
- 卡通化 UI 弹窗与"+10%"飘字

### 5.2 主导 vs 伴随

**主导特效（占槽位）**：长生命的视觉信号，构成画面"特效元素"。**任意时刻只 1 种**。
- 鬼火粒子、尘飘、月光柱、晨光柱、摸摸轨迹光痕、**训狗字符浮起**

**伴随行为（不占槽位）**：瞬时动态行为，不构成视觉"元素"，可与主导特效叠加。
- 屏震、白闪、镜头推拉/平移、聚焦模糊、烈焰爆开（瞬时）

> 判断标准：**这个特效如果消失了，玩家会觉得"画面少了什么东西"** → 主导（占槽位）；**消失只是"动作没发生"** → 伴随（不占槽位）。

### 5.3 主导特效切换

新主导进入 → 旧主导淡出。同一时刻不会有两种粒子常驻。

例：场景 5 焦土的尘飘 → 场景 6 洞穴的月光柱——切场景时尘飘退场，月光柱入场。中间允许有一拍空档，强化场景切换。

### 5.4 训狗字符浮起：归特效层的特例

**训狗诗字符浮起归特效层，不归文字层**——这是有意区分。

- 文字层（paragraph）= 旁白与对白，常态文本，打字机
- 特效层 · 训狗字符 = 一次性的"画面里的字"，墨迹由淡到浓、字符逐个浮起，视觉上是**特效**而不是**叙事文本**
- 这样玩家能从视觉风格直接区分"主控正在听到的旁白"和"墙上刻的字"

**这是特效层唯一允许的"画文字"**。其他场合不画 SVG 文字，也不画 SVG 物件。

## 六、单元素原则汇总

| 层 | 同时存在数 | 切换方式 |
|---|---|---|
| 场景层 | 1 个元素（PNG 或整图局部） | 同源 = 露出区域变化；异源 = 旧淡出 / 新淡入 |
| 角色层 | 不约束（剧情主控+他） | 现有逻辑 |
| 氛围层 · env | 0 或 1 种 | 渐变过渡（300-1500ms） |
| 氛围层 · emotion | 0 或 1 种 | 渐变过渡 |
| 特效·主导 | 0 或 1 种 | 旧淡出 / 新入场 |
| 特效·伴随 | 不约束（屏震/闪/推拉可任意叠加） | 瞬时触发 |
| UI 层 | 不约束 | 现有逻辑 |
| 文字层 | 1 段（同时只显示当前段） | 现有 paragraph 逻辑 |

## 七、Z-order 与混合模式（实现锚定）

| 顺序 | 层 | DOM 容器 | 混合模式 | 备注 |
|---|---|---|---|---|
| ① | 极暗底 | `.screen-bg-color` | normal | bgColor |
| ② | 场景层 - 单体 | `.scene-el` | normal | PNG 切图 |
| ② | 场景层 - 整图 + 遮罩 | `.scene-bg-image` + `mask-image` | normal | radial / linear gradient mask |
| ③ | 氛围层 · env | `.atmo-env` | `multiply` 或 `overlay` | 染场景，不染角色 |

| ⑧ | 圆弧 / UI | `.ring-layer` | normal | ring.js / swipeTip.js |
| ⑨ | 文字 | `.para-zone` | normal | paragraph.js |

## 八、状态机：每个 beat 的视觉声明

每个剧情 beat 可以**只声明改变量**，未声明的层保持当前状态：

```
beat-level 视觉声明（伪结构）：
{
  scene:    { src?, reveal? } | null   // 切换场景层元素；null = 移除
  env:      'preset' | params | null   // 环境氛围切换；null = 清空
  emotion:  'preset' | params | null   // 心理氛围切换；null = 清空
  fx:       'preset' | null            // 主导特效切换；null = 清空
  burst:    [ { kind, ... } ]          // 伴随行为，瞬时
}
```

**默认行为**：
- 切场景 beat = 触发场景层与 env 切换；emotion 与主导特效重置为空
- 段间 beat = 未声明的层不变

## 十、与之前一版的差异

- ❌ 删除"整图局部 vs 单体"两种模式 → 两条平行的素材路线，**功能等价**
- ❌ 删除"角色身上的氛围光（rim-light / local-tint / aura-bloom）" → 不存在这个概念
- ❌ 删除"整图 + 单体共存"假设 → 同一画面不混搭
- ✅ 重新引入 env / emotion 区分 → 但只在"挂载位"层面（角色之下 vs 之上），参数系统统一
- ✅ 整图遮罩支持线性形状（上半/下半/左半/右半）
- ✅ 训狗字符浮起归特效层（不归文字层），用风格区分"画里的字"与"旁白"
- ✅ 新增"单元素原则"为顶层硬约束
- ✅ 新增"主导特效 vs 伴随行为"的区分
