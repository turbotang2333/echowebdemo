# Demo · 完整剧本 (v2)

> 配套：[demo-flow.md](demo-flow.md)（节奏与结构方案）
> 本文档定义 8 个场景屏的所有台词、旁白、立绘指令与用户操作。每段内容与用户下一步操作 1:1 对应。

## v2 主要变更（相对 v1）

**上滑成为唯一推进操作。** 原 v1 中的"点按推进同屏段落"改为"上滑推进同屏段落"，统一手势，靠视觉力度区分大小。理由见 [demo-flow.md](demo-flow.md) v4 变更说明。

- `[点按]` 推进 → 全部改为 `[上滑·轻]` 推进（约 18 处）
- `[上滑]` 切场景 → 全部改为 `[上滑·切场]`（7 处）
- `[点按]` 降级为辅助：仅用于"催当前文字打字机展开完成"

---

## 用户操作速查

| 标签 | 操作 | 含义 |
|---|---|---|
| `[长按]` | 长按圆弧 | 你说话（语音输入） |
| `[上滑·轻]` | 向上滑动屏幕 | 屏内推进下一段（背景不动，文字淡入淡出） |
| `[上滑·切场]` | 向上滑动屏幕 | 切到下一个场景（整屏推走 + 新场景浮入 + 滚动效果） |
| `[摸摸]` | 在立绘上持续移动手指 | 抚摸 |
| `[点按]`（辅助） | 点按屏幕 | 把当前正在展开的文字一次性显示完，**不**推进 |
| `[自动]` | 无需操作 | 自动播放 |

**通用规则**：
- **手势统一**：用户始终只做"向上滑动"这一个推进动作。系统根据当前位置自动判断是"轻"（屏内段间）还是"切场"（屏内最后一段已播完）。两者动画力度不同，用户能自然区分。
- **文字展开中上滑** = 等同点按催文字，立即展开当前段、**不**推进。展开完成后再次上滑 = 推进。
- **圆弧期间上滑无效**——必须长按说话或选"不出声"完成对话节点。
- **摸摸期间**手指松开 = 进度回退 30%，2s 内回来继续算；超过 2s 彻底失败回退到摸摸开始前。

---

**摸摸节拍**

→ `[摸摸]` 持续移动手指 · 累积约 5s 有效"摸"时间

> **敏感区**
> - 耳朵（头顶两侧）：×1.5 进度 + 耳朵颤一下 + 微高光
> - 下巴（颌下）：×1.3 进度 + 头部被轻抬
> - 头顶（头部中央）：×1.2 进度 + 眯眼
> - 其他区域：×1.0 进度，无局部反应

> **4 阶状态变化**（按累积进度切换整体姿态）
> - 0% → 25%：他僵住、警惕（pose: tense）
> - 25% → 50%：耳朵开始放松（pose: relaxing），无文字
> - 50% → 75%：眯眼（pose: squint），无文字
> - 75% → 100%：尾巴卷上来蹭手（pose: tail-curl），无文字

> **手指反馈**
> - 当前位置：微小柔光跟随
> - 移动轨迹：金线尾迹（衰减 0.5s）
> - 划过敏感区：该区瞬时高光

> **不要进度条 UI**——所有反馈靠狐狸的身体反应表现。

→ 累积满 100% · 自动进入下一段

---

**旁白 4**（摸摸完成后）

## 与现有产品结构的映射

现有 [js/script.js](../../js/script.js) 是 SCRIPT 数组，每个事件 `{ t: 'xxx', ... }`。本剧本可映射为：

| 剧本元素 | 现有事件类型 | 改动 |
|---|---|---|
| 屏初始化 | `bg` / `scene` / `char-pos` / `pose` | 已有 |
| 旁白段落 | `narration` | 已有，需扩展为长段（40-80 字） |
| 角色台词 | `dialogue` | 已有 |
| 圆弧（含引导文字） | `user-input` | 已有，需扩展 `placeholder` 字段承载引导 |
| 自动停留 | `pause` | 已有 |
| 场景内动效 | `art-set` / `scene-update` / `shake` | 已有 |
| **段落淡入淡出**（屏内段间） | — | **新增** `paragraph-fade` 或在 `narration` 上加 `fade` 字段 |
| **上滑·轻**（推进同屏下一段） | — | **新增** `await-swipe` 事件，由系统判断当前位置触发"段间过渡"动画（淡入淡出，约 300ms） |
| **上滑·切场**（切下一场景） | — | 同上 `await-swipe`，触发"切场过渡"动画（整屏推走+浮入+滚动，约 600ms） |
| **点按催文字**（辅助） | — | **新增** 点按监听：文字打字机展开过程中点按 = 立即展开完整；展开完成后点按 = 等同上滑 |
| **摸摸（升级）** | `await-pet`（已有简版） | **重写**：持续移动判定、敏感区、4 阶进度、轨迹光痕 |

**关键实现要点**：上滑监听器只暴露一个 `await-swipe`，由 player 内部根据当前段位置（屏内段间 vs 屏内最后一段）决定调用哪个过渡动画。剧本作者无需关心轻/重区分。

实现优先级见 [demo-flow.md](demo-flow.md) 第十节。
