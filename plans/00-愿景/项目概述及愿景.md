# "Echo(回响)"产品设计逻辑梳理

> 顶层产品愿景。这是 Echo 跨任何具体落地版本不变的产品哲学,也是给开发团队的**设计手册 + 交互手册**起点。
>
> **配套层**:
>
> - [通用设计规范](../01-通用设计规范/) —— 从愿景沉淀的、引擎无关的设计规则(交互、视觉表现)
> - [测试版](../02-测试版/) —— 当前在调试的实验版,所有要沉淀的设计都会陆续回写到通用规范
>
> 📌 实施现状(哪些已稳定可直接参考、哪些还在迭代、哪些尚未实施)见 [§六 实施现状](#六-实施现状2026-05)。

## 一、 设计哲学:从"游戏工具"到"生命介入"
*   **痛点诊断：**
    *   **传统乙游：** 剧情固定、分支简单、用户参与感弱。
    *   **现有AI陪伴：** 局限于“虚拟手机”或“对话框”形态，工具感太强，缺乏真实世界的浸润感。
*   **核心理念：** **“打破 UI 的局限与边界”**。
    *   产品不再是一个充满按钮的 App，而是一个通往男主世界的“窗口”。
    *   将用户从“玩游戏的人”转变为“介入男主生活的真实存在”。

---

## 二、 交互逻辑：极简即深度的“无界体验”
为了降低学习成本并增强临场感，产品将交互简化为两个核心动作：

1.  **长按“回响弧”（语音输入/共鸣）：**
    *   **形态：** 画面中下方唯一的抽象圆弧，象征声音的回响与闭环。
    *   **反馈：** 长按时产生波纹，用户直接进行语音对话。
    *   **逻辑：** 这种非文本的交互模拟了现实中的“发声”，强化了“他在你面前，能听到你”的错觉。
2.  **上滑“无限流”（剧情推进/生长）：**
    *   **形态：** 采用用户已成生理习惯的“抖音式”交互。
    *   **逻辑：** 剧情不再是翻页，而是**“无限生成”**。由 **AI Agent 导演**实时编排，根据用户的语音内容即时分发后续场景、画面与对话。
    *   **内容分发：** 在沉浸式的剧情流中，无缝插入高光视频、互动小游戏或特定情节，随用随走。

---

## 三、 角色逻辑：具有独立人格与时间线的 Agent
*   **自主性设计：** 角色不再是 24 小时待命的电子宠物。
    *   他有自己的时间线和要忙的事。当他需要“工作”或“独处”时，他会离开画面或处于非活跃状态。
    *   这种“不在线”反而赋予了角色真实的**人格生命力**，形成了更高级的陪伴形态。
*   **对话驱动：** 剧情的走向完全由用户的自由输入驱动，用户的意志会实时反映在男主的反馈和后续场景中。

---

## 四、 价值逻辑：记忆资产化与人格星图
这是产品从“体验”转向“沉淀”的关键层级，解决了内容“随用随走”后的留存问题。

1.  **人格星图（Depth）：**
    *   用户与角色的互动不是为了通关，而是为了“拼凑”他完整的人格。
    *   通过持续沟通，解锁他的过去、痛苦、故事，最终形成一张宏大的人格全景。
2.  **记忆星图（Assets）：**
    *   **流式内容静态化：** 那些在无限流中消失的即时对话和视频，会转化为“记忆点”存储在星图中。
    *   **情感资产：** 界面是一整张无限延展的星图，它是用户与角色共同经历的物化表现，是不可逆的、专属于用户的“关系资产”。

---

## 五、 落地产品形态总结

| 维度 | 产品落地表现 |
| :--- | :--- |
| **视觉呈现** | **极简无界：** 无传统按钮、无边框。仅保留图片/视频、文本气泡及底部的“回响弧”。 |
| **核心交互** | **长按语音**（输入） + **上滑**（内容生成与推进）。 |
| **剧情机制** | **AI 导演驱动：** 无限流、无限画布，实时根据对话内容生长剧情。 |
| **系统架构** | **双层结构：** 上层是“即时互动流”（沉浸体验）；下层是“无限星图”（记忆资产与深度人格）。 |
| **愿景延伸** | **去屏幕化：** 逻辑基于全对话。未来可无缝迁移至智能眼镜、智能音箱、车载等硬件。 |

### 6.3 未实施(下一阶段才开始接入)

**核心 AI 机制**

- AI Agent 导演实时编排剧情
- 无限生成的剧情流(测试版是预制 8 场 600 秒,非生成式)

**角色机制**

- 角色独立时间线 / 不在线人格(测试版全程角色都在场)
- 用户意志实时反映在角色反馈与后续场景

**价值沉淀机制**

- 人格星图(Depth):通过对话拼凑角色完整人格
- 记忆星图(Assets):流式内容静态化为关系资产
- 即时流 + 无限星图双层架构

**形态扩展**

- 去屏幕化(智能眼镜 / 智能音箱 / 车载)

### 6.4 测试版的定位

测试版**不是愿景的预演**,而是给愿景**预留好的舞台**——把「视觉表现 + 交互骨架」打稳,等 AI Agent 导演与无限流接入时,画面表达这一基础设施已足够稳健。所有要提炼的设计都会从测试版陆续沉淀到通用规范。

## 七、 文档体系

| 层 | 用途 | 跨版本变化 |
|---|---|---|
| **愿景**(本文) | 顶层产品哲学 | 不变 |
| **通用设计规范** | 从愿景沉淀的引擎无关规则 | 缓慢演进 |
| **测试版** | 当前 demo 的剧本 / 素材 / 实现 | 跟版本绑死 |

**新文档应归哪层?**

- 跨任何 Echo 形态都成立的产品理念 → 愿景层
- 跨任何引擎、跨任何具体剧本的设计规则 → 通用设计规范
- 跟具体素材 / 剧本 / DOM / 数值绑死的 → 测试版
