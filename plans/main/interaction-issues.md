# 交互层面可优化问题

## 高优先级

### 1. 长按没有进度反馈
- 用户按住底部弧线时，没有"正在按住"的渐进视觉变化
- 新手不知道要按多久、是否按对了位置
- 相关代码：`js/input.js:44`（250ms 长按阈值）

### 2. 字幕/旁白无法快进
- 对话/旁白逐字显示，点击屏幕无法跳过
- 重玩时等待体验很差
- `js/signal.js` 已定义 `setFastForward` 但全项目无处调用，快进机制缺入口

### 3. Endmark 要求打开日志才能推进
- 故事结尾需要用户打开回忆录才能继续
- 提示"试着从左上角拉开这一段的回忆"很不起眼
- 左上角光点暗示性弱，用户可能卡住
- 相关代码：`js/player.js:36-51`

### 4. Edge Zone 在 idle 状态仍拦截触摸
- 屏幕下方1/3区域始终接收触摸事件
- `state-idle` 时弧线完全透明，触摸无反应却占用了区域
- 相关代码：`style.css:379-381`（最小高度200px）

### 5. 用户输入是"假选择"
- 回响阶段提供了4个选项（如"凉的/温的/烫的/说不清"）
- 但 `collectAnswer` 始终使用写死的 `presetText`，无论选什么结果一样
- 用户可能产生选择预期落空的不满
- 相关代码：`js/echo-prologue.js:165-183`

## 中优先级

### 6. 气泡定位与角色动画不同步
- 角色做 pose 过渡需要 1.4s
- 对话气泡根据瞬间的头位置放置，动画未完成时气泡已出现
- 导致气泡与角色头部位置错位
- 相关代码：`js/text.js:73`，`style.css:251-256`

### 7. 时序文本无法暂停
- 旁白有固定存活时间（3500ms），内心独白（3500ms），重旁白（4500ms）
- 用户无法暂停让文字停留，没有全局暂停机制
- 相关代码：`js/text.js:5-7`

### 8. 日志每次打开从顶部开始
- `openJournal()` 每次将 `scrollTop` 设回 0
- 内容多时用户需要重新滚动到之前阅读位置
- 相关代码：`js/journal.js:41`

### 9. 场景装饰素材未预加载
- `index.html` 只预加载了 cj1-cj5 和 xiaohuli.png
- art 元素的 SVG（叶/焰/花等）按需加载
- 慢网络下可能出现视觉闪烁

### 10. 日志锚点触摸目标过小
- `#journal-anchor` 只有 22×22px
- 远低于移动端推荐最低 44×44px，误触率高
- 相关代码：`style.css:331-338`

## 低优先级

### 11. 屏幕方向不可绕过
- 横竖屏切换必须正确方向，没有"继续浏览"的旁路
- 某些设备 `matchMedia` 可能报告错误，用户被永久卡住
- 相关代码：`js/orientation.js`

### 12. 键盘交互不完整
- Space 键模拟长按弧线，J 键开关日志
- 但没有键盘快捷键跳过当前文本或触发其他点击目标

### 13. 交互模式不一致
- Echo Prologue：长按弧线 + hint 列表选择
- 主剧情：长按弧线但文字固定
- Run 场景：突然变成点击脉冲点
- 三种交互模式增加认知负荷

### 14. 无进度指示
- 用户无法感知故事推进到百分之多少
- 缺少微妙的进度反馈
