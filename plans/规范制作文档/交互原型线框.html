§3手势

上滑 推进剧情
  • 底部尖尖呼吸态
  • 跟手向上拱起
  • 阈值 → 旧屏离场
  • 未达 → 平滑回弹
长按 语音对话
  • 圆弧弹起 + 涟漪
  • 进入语音对话节点
  • 首二次伴随 hint
点击 入口 / 收回 / 启动
  • 左上角 → 展开历史
  • 空白处 → 收回抽屉
  • 启动遮罩 → 开始
所有交互只用三种手势完成，位置与形态不重叠：尖尖在底中、圆弧弹起在下半、入口固定左上。

§5屏切换时序

FRAME 01
起手
用户开始上滑 · 旧屏在位 · 立绘锁定。
FRAME 02
过渡
旧屏向上推走 · 新屏从下入场 · 立绘不参与位移 · clearAllText() 兜底。
FRAME 03
落定
新屏就位 · 旧屏 host 销毁 · 立绘进入新姿态 · 氛围/特效按新屏配置重启。
立绘做成全局单例 · 角色感觉像跟着观众一起穿越场景，而不是每个场景重新出现一遍。
