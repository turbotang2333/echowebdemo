> v2 的设计宪法。涵盖**交互语义**与**视觉层级**两件事，凡是与"用户能感知到什么、画面怎么分层"相关的硬约束都写在这里。

## 一、交互语义

v2 全程基础交互极简，向短视频"刷"语义对齐。**对用户而言只有一种"上滑"**——展示什么由系统按推进阶段自动决定，对用户透明。

| 交互 | 含义 | 触发条件 | 反馈 |
|---|---|---|---|
| **上滑** | 推进 | 当前段已展开完成 | 系统按推进阶段决定展示什么——屏内还有未播段落 → 同屏推进下一段（背景不动，立绘可微动）；屏内已播完 → 切到下一个场景（整屏向上推走 + 新场景从下浮入） |
| **圆弧长按** | 你说话 | 屏内对话节点 | 圆弧浮起 + 语音/文字输入 |
| **点按**（待开发） | 后续承担剧情新入口 | — | 部分节点点击后进入新界面；当前阶段未实现 |

**关键原则**：

- 上滑是唯一推进操作。用户始终只做"上滑"这一个动作，**同屏推进还是切场景由系统按需求阶段自动判断**，不暴露"轻/重"两套语义
- 一段文字 = 40-80 字、2-3 句，承载一个完整动作或心理转折
- 圆弧期间上滑无效——必须长按说话或选"不出声"完成
- 点按目前未实现，后续会作为某些节点的"开启新入口"，点击后进入新界面（不替代上滑的推进逻辑）

## 二、互动玩法（小游戏交互）

基础交互语义之外的非线性玩法，承载更深的情感或行为表达，规则独立于上滑/长按。进入互动玩法时基础推进操作临时让位。

| 玩法 | 出现节点 | 操作 | 反馈 |
|---|---|---|---|
| **摸摸**（持续移动） | 第 7 场景的亲密点 | 手指在立绘上持续移动抚摸 | 立绘局部反应、轨迹光痕、敏感区命中；松开 = 进度回退 30%，2s 内回来继续算；超过 2s 彻底失败 |

> 后续会扩充更多互动玩法。每种玩法都有独立的操作规则与反馈逻辑。

## 三、视觉层级堆栈

```
┌──────────────────────────────────────────┐
│ ⑪ 交互 UI 层（圆弧/手势 tip）           │ ring.js / swipeTip.js
├──────────────────────────────────────────┤
│ ⑩ 特效·伴随（屏震/闪/推拉，瞬时）       │ ★ 全屏，文字之上
├──────────────────────────────────────────┤
│ ⑨ 文字层（旁白/对白/inner/aside）       │ paragraph.js
├──────────────────────────────────────────┤
│ ⑧ 氛围层 · emotion（染整张画面）        │ ★ 含前景，文字之下
├──────────────────────────────────────────┤
│ ⑦ 主导特效·前（角色前粒子/光等）         │ ★ 与·后 二选一
├──────────────────────────────────────────┤
│ ⑥ 场景·前景（PNG/整图，角色前）          │ ★ 单元素·前
├──────────────────────────────────────────┤
│ ⑤ 角色层                                 │ character.js
├──────────────────────────────────────────┤
│ ④ 主导特效·后（角色后光柱/雾等）         │ ★ 与·前 二选一
├──────────────────────────────────────────┤
│ ③ 氛围层 · env（染场景前景+后景）        │ —
├──────────────────────────────────────────┤
│ ② 场景·后景（PNG/整图，角色后）          │ ★ 单元素·后
├──────────────────────────────────────────┤
│ ① 极暗底（bgColor 纯黑/深色）            │ —
└──────────────────────────────────────────┘
```

**单元素原则（最关键）**：

- **场景层**：拆**前景**（角色之前）与**后景**（角色之后）两个槽位，各 0-1 个元素，互不影响（同时最多 2 个，且同一槽位内仍是单元素）。来源可以是 PNG 切图，也可以是整图局部露出
- **当前进度**：所有现存素材均按后景处理；前景是预留扩展位，未来用于近景遮挡（窗框、藤蔓、近景物件等）
- **氛围层**：env 与 emotion 各 0-1 个 preset，**可同时存在**（env 染场景前景+后景，emotion 染整张画面包括前景）
- **主导特效**：任意时刻只 1 种主导特效在屏。挂前（角色之前）还是挂后（角色之后）由剧情按需指定，**前/后二选一不同时**
- **特效·伴随**：不占视觉槽位；瞬时全屏覆盖至文字之上、交互 UI 之下，可任意叠加

## 四、场景层

**核心定义**：场景层 = 画面中可识别的具象元素。分**前景**（角色之前）与**后景**（角色之后）两个独立槽位，各 0-1 个，互不影响。覆盖率沿用设计：20-30% / 50-60% / 100%（以后景为主统计）。

**当前进度**：所有现存素材均作后景使用；前景为预留扩展位，未来承载近景遮挡（窗框、藤蔓、近景物件等）。前后景之间不互转——前是前、后是后，由素材在剧本里的角色决定。

### 4.1 两条素材路线（并列等价）

| 路线 | 含义 |
|---|---|
| **PNG 切图** | 一张干净的透明 PNG（鱼尾、藤蔓、食人花……），整张图就是一个单体 |
| **整图局部露出** | 整张场景图（骸骨、宅院、羊人吃尸体……）通过遮罩控制露出区域，**这块区域 = 一个单体** |

> 一张整图可以承载多个单体（露出不同区域 = 不同单体）。整图与切图**不在同一画面共存**。

### 4.2 整图遮罩形状

整图永远以 cover 100% 铺，露出靠遮罩控制：遮罩内是图，遮罩外是极暗底。

- **椭圆遮罩**（默认）：中心 `(cx, cy)`、半径 `(rx, ry)`、柔边
- **线性遮罩**：上半区 / 下半区 / 左半区 / 右半区

### 4.3 单元素切换

- **同源切换**（同一张整图露出不同区域）：旧露出区域**渐变扩大、缩小或位移**到新区域
- **异源切换**（换成另一张图的单体）：旧元素淡出 → 极暗底瞬间 → 新元素淡入

### 4.4 留白即设计

被压暗 / 不在露出区域 / 没有切图覆盖的部分，全部交给极暗底。**留白本身是设计**——给玩家想象空间。

## 五、氛围层

### 5.1 双挂载位

| 模式 | 表达 | 挂载位 | 染色范围 |
|---|---|---|---|
| **env** | 环境氛围：明暗、时间、天气、地点性 | 角色之下 | 只染场景前景与后景 |
| **emotion** | 心理氛围：冷漠、亲密、惊吓、愤怒 | 文字之下、所有视觉之上 | 染整张画面（场景前后景 + 角色 + 主导特效，**含前景**） |

**为什么分两个挂载位**：env 在底保护角色色调一致性；emotion 在顶让心理冲击成为整体感受。"美好晨光下心境忽然变冷" = env(`dawn-warm`) + emotion(`cold-shock`) 一闪。

### 5.2 氛围预设清单

| Preset | 建议模式 | tint | blend | vignette | 用途 |
|---|---|---|---|---|---|
| `dark-water` | env | 深蓝 rgba(20,35,70,0.85) | multiply | 0.55 | 场 1 黑暗水中 |
| `cold-blue` | env | 冷蓝 rgba(70,110,180,0.75) | overlay | 0.4 | 场 4 火林 / 场 6 月夜洞穴 |
| `flame-warm` | env | 暖橙 rgba(255,140,60,0.5) | overlay | 0.15 | 场 4 烈焰救场 |
| `scorched` | env | 灰红 rgba(180,95,60,0.7) | overlay | 0.4 | 场 5 焦土 |
| `dawn-warm` | env | 暖橙黄 rgba(255,195,135,0.55) | overlay | 0 | 场 7 晨光 / 场 8 入场 |
| `fog-mansion` | env | 灰白偏冷 rgba(170,165,180,0.7) | multiply | 0.45 | 场 8 钩子宅院 |
| `flush-rose` | emotion | 暖粉 rgba(255,150,150,0.35) | screen | 0 | 摸摸 50-100% 脸红 |
| `cold-shock` | emotion | 金红 rgba(255,70,70,0.5) | multiply | 0.3 | 钩子瞳缩瞬间 |
| `red-alert` | emotion | 全屏红 rgba(180,30,30,0.55) | multiply | 0.5 | 危险/愤怒瞬间 |

> 预设清单不是封闭的。剧本推进时可以新增，加在 [v2/js/atmo.js](../../v2/js/atmo.js) `PRESETS`。

### 5.3 切换规则

- 切场景 beat → env 渐变到新场景的默认预设；emotion 重置为空
- 段落推进 → 默认不变，剧情明确需要时切（摸摸 4 阶就是 4 次氛围切换）
- emotion 入场时 env 不退——env 维持环境基调，emotion 在顶加情绪冲击

### 5.4 立绘差异度低时的协作

当立绘资产差异度不够（如摸摸 4 阶几乎同姿态）时，**emotion 氛围切换是补强主力**：

```
摸摸:    0% → 25% → 50% → 75% → 100%
env:     dawn-warm（不动）
emotion: 无 → 无 → flush-rose浅 → flush-rose → 无（让 dawn-warm 接管）
立绘:    原图  原图  脸红切图     脸红切图   闭眼笑切图
```

立绘单看几乎不变，配合 emotion 递进 + 特效，体验上有清晰梯度。

## 六、特效层

### 6.1 哲学：克制 + 抽象

> 前端直接画的写实细节几乎一定廉价。能用粒子、光、震动表达的，就不画 SVG 物件。

**允许 ✅**：抽象粒子（鬼火、尘、训狗字符浮起）/ 体积光（月光柱、阳光柱——是光不是模拟物）/ 全屏动态（屏震、白闪、镜头推拉）/ 短促色彩失真

**禁止 ❌**：在角色身体上画 SVG（手腕画绳子、嘴角描红线）/ 写实物件 SVG（杯子、果子）/ 卡通化 UI 弹窗与"+10%"飘字

**不要用粒子模拟具象物 ⚠️**：粒子的"点"化抽象 OK（鬼火 = 单点光），但**不要试图用粒子模拟具象的火焰/雾团/烟雾/血雨/水花**——团状颗粒模拟物会塑料感很重。具象冲击靠**整图素材闪现 + 闪/震/明暗 ramp** 实现：
- 烈焰救场 → 整图（cj2 红死潭）短暂叠 brightness 1.4 + flash + shake
- 雾涌起 → CSS 半透白板 + `mix-blend: screen` + opacity ramp（不用粒子云）
- 撕碎瞬间 → 整图一帧闪现 0.3s（不用粒子血/水）

判别标准：**这玩意儿在现实里有具体形态吗？** 有 → 整图素材；没有（鬼火、尘、光柱）→ 粒子。

### 6.2 主导 vs 伴随

| 类别 | 含义 | 占槽位 | 任意时刻最多 | 例子 |
|---|---|---|---|---|
| **主导** | 长生命的视觉信号，构成画面"特效元素" | ✅ | 1 种（前/后二选一） | 鬼火、尘飘、月光柱、晨光柱、训狗字符浮起 |
| **伴随** | 瞬时动态行为，不构成视觉"元素" | ❌ | 任意叠加 | 屏震、白闪、镜头推拉、烈焰爆开 |
| **切换** | 状态切换（开/关） | ❌ | 任意叠加 | 雾、灯笼、纸扎人 |

> 判断标准：**这个特效如果消失了，玩家会觉得"画面少了什么东西"** → 主导；**消失只是"动作没发生"** → 伴随。

**主导特效的"前/后"**：每个主导特效声明时需指定 `position: 'front' | 'back'`——挂角色之前（粒子飘过面前、训狗字符浮在身前）或角色之后（背后光柱、远处雾）。位置由剧情表达决定，**任意时刻屏内只允许一种主导特效，且只在一侧**，不允许前后同时各挂一个。

**特效·伴随的位置**：伴随类（屏震/白闪/全屏色块）覆盖至文字之上、交互 UI 之下——剧情冲击瞬间字也被吃掉，但圆弧仍可点。屏震 / 镜头推拉本质是对整个 stage 的 transform，不占独立层。

### 6.3 训狗字符浮起：特例

训狗诗字符浮起归特效层（不归文字层），用墨迹由淡到浓 / 字符逐个浮起的视觉风格区分"画里的字"与"旁白文本"。**这是特效层唯一允许的"画文字"**。

## 七、覆盖率口径（节奏起伏图的 Y 轴）

| 状态 | 计入 | 互斥关系 |
|---|---|---|
| 纯极暗 bg | 0% | — |
| **单体 PNG 集**（1-N 个） | 累加 20→70% | 互斥组 A |
| **整图 reveal mask** | mask 面积百分比（25→70%） | 互斥组 A |
| **整图全揭** | 100% | 互斥组 A |

**互斥组 A**（单体集 / 整图 mask / 整图全揭）三选一，同时只能存在一种。**单体之间可叠加**。

**前/后景的覆盖率口径**：覆盖率以**场景·后景**为主统计；前景作为遮挡装饰一般小面积出现，不计入主覆盖率（前景独立有无不影响节奏起伏曲线的形状）。

### 7.1 设计目标

- 50% 时间停留在 **20-30%**（单体探索期）
- 中段叠加扩到 **50-60%**（多单体 / 局部扩大）
- 高潮整图全揭 **100%**

详见 [节奏起伏.html](节奏起伏.html)。

cj1.jpg / cj2.jpg / cj3.jpg（场 2/3/7 整张 bg、无 reveal）暂按 100% 全揭计算。正式分类待素材重评估，详见 [素材清单.md §四](素材清单.md)。

## 九、状态机：每个 beat 的视觉声明

每个剧情 beat 可以**只声明改变量**，未声明的层保持当前状态：

```js
{ t: 'scene-back',  el: '鱼尾.webp' }            // 设置后景单体
{ t: 'scene-back',  reveal: { shape: 'ellipse', cx, cy, rx, ry } }  // 后景遮罩
{ t: 'scene-back',  clear: true }                // 清空后景
{ t: 'scene-front', el: '藤蔓.webp' }            // 设置前景单体（预留扩展）
{ t: 'scene-front', clear: true }                // 清空前景
{ t: 'env',         preset: 'dark-water' }       // 切换 env
{ t: 'env',         clear: true }                // 清空 env
{ t: 'emotion',     preset: 'cold-shock' }       // 切换 emotion
{ t: 'emotion',     clear: true }                // 清空 emotion
{ t: 'fx-dominant', kind: 'ghost-fire', position: 'back'  }  // 主导特效，挂角色后
{ t: 'fx-dominant', kind: 'spark',      position: 'front' }  // 主导特效，挂角色前
{ t: 'fx-dominant', clear: true }                // 清空主导特效（不论前后）
{ t: 'burst',       kind: 'shake', duration: 200 }  // 触发伴随行为
```

> **主导特效切换语义**：声明新的 `fx-dominant` 时若已有主导特效在屏，无论新旧 `position` 是否相同，旧的先淡出再上新——任意时刻只允许一种主导特效在一侧。

**默认行为**：
- 切场景 beat = 触发场景前/后景与 env 切换；emotion 与主导特效重置为空
- 段间 beat = 未声明的层不变
