# 通用设计规范 · 表现设计

> Echo 的视觉表现硬约束。本文不绑定任何具体引擎或前端实现,描述的是「画面由哪些图层组成、每层做什么、怎么组合、怎么变化」。

## 一、视觉层级堆栈

图层按「向下覆盖责任」分组:每组顶层向下染本组所辖范围,组与组之间通过角色这条"视觉中轴"分隔。

### 图层栈(自顶向下)

```
   ━━━━━━━━━━━━━ 表面层(独立显示,不向下覆盖)━━━━━━━━━━━━

   ⑪ 交互 UI(圆弧、手势提示)
   ⑩ 交互特效(屏震、闪、镜头推拉等瞬时全屏)
   ⑨ 文字层(旁白、对白、内心独白)

   ━━━━━━━━━━━━━ 前景组(向下覆盖责任) ━━━━━━━━━━━━━━

   ⑧ 心境氛围      ◇ 组顶氛围统帅,染整画(前景所有层 + 角色 + 后景)
   ⑦ 前景主特效    ◈ 与 ③ 二选一
   ⑥ 场景前景      ◉ 与 ② 同族双槽位

   ━━━━━━━━━━━━━ 视觉中轴 ━━━━━━━━━━━━━━━━━━━━━━━━

   ⑤ 角色层(立绘)                                       ★

   ━━━━━━━━━━━━━ 后景组(向下覆盖责任) ━━━━━━━━━━━━━━

   ④ 环境氛围      ◇ 组顶氛围统帅,染后景区(后景主特效 + 场景后景)
   ③ 后景主特效    ◈ 与 ⑦ 二选一
   ② 场景后景      ◉ 与 ⑥ 同族双槽位

   ━━━━━━━━━━━━━ 底色 ━━━━━━━━━━━━━━━━━━━━━━━━━━

   ① 极暗底(纯黑或深色)
```

### 类型族关系(前后组三对镜像 + 表面层独立特效)

| 符号 | 类型族 | 前景组成员 | 后景组成员 | 约束 |
|---|---|---|---|---|
| ◇ | 氛围统帅(各组顶层) | ⑧ 心境氛围 | ④ 环境氛围 | 各管各组,可同时存在 |
| ◈ | 主导特效(各组中层) | ⑦ 前景主特效 | ③ 后景主特效 | 前后二选一,不同时 |
| ◉ | 场景层(各组底层) | ⑥ 场景前景 | ② 场景后景 | 双槽位,可同时存在 |
| ▲ | 交互特效(表面层) | ⑩ | — | 不占槽位,任意叠加、瞬时 |

### 单元素原则(最关键的硬约束)

- **场景层**:前景与后景各 0-1 个元素,同槽位内单元素。来源可以是透明位图切图,也可以是整图通过遮罩局部露出
- **氛围层**:心境氛围与环境氛围各 0-1 个预设,**各管各组、可同时存在**(心境氛围染整画,环境氛围染后景区)
- **主导特效**:任意时刻只 1 种主导特效在屏,**前 / 后二选一不同时**
- **交互特效**:不占视觉槽位;瞬时全屏覆盖至文字之上、交互 UI 之下,**可任意叠加**

> 各落地版本的图层栈 → 渲染容器映射、染色叠加的具体写法,见各自的实现锚文档(例如 测试版 见 [测试版 / 实现锚-DOM与CSS.md](../02-测试版/实现锚-DOM与CSS.md))。

## 二、场景层

**核心定义**:场景层 = 画面中可识别的具象元素。分**前景**(角色之前)与**后景**(角色之后)两个独立槽位,各 0-1 个,互不影响。

### 2.1 两条素材路线(并列等价)

| 路线 | 含义 |
|---|---|
| **透明位图切图** | 一张干净的、带透明通道的整体素材(鱼尾、藤蔓、食人花等),整张图就是一个单体 |
| **整图局部露出** | 一张构图完整的场景图(骸骨地、宅院、洞穴等)通过遮罩控制露出区域,**这块区域 = 一个单体** |

> 一张整图可以承载多个单体(露出不同区域 = 不同单体)。整图与切图**不在同一画面共存**。

### 2.2 整图的显示规则

整图素材以全幅显示,通过遮罩控制可见区域:**遮罩内显示图像,遮罩外露出极暗底**。

### 2.3 遮罩形状

- **椭圆遮罩**(默认):中心点 + 横纵半径 + 柔边宽度
- **线性遮罩**:上半区 / 下半区 / 左半区 / 右半区

### 2.4 单元素切换

- **同源切换**(同一张整图露出不同区域):旧露出区域**渐变扩大、缩小或位移**到新区域,整图本身不换
- **异源切换**(换成另一张图的单体):旧元素淡出 → 极暗底瞬间 → 新元素淡入

### 2.5 留白即设计

被压暗 / 不在露出区域 / 没有切图覆盖的部分,全部交给极暗底。**留白本身是设计**——给玩家想象空间,而不是「缺素材」。

## 三、氛围层

### 3.1 两个氛围层的职责

氛围层作为各组的「向下覆盖统帅」,统一染本组所辖范围。两层氛围在表达上分工:

| 层 | 位置 | 表达 | 染色范围 |
|---|---|---|---|
| **心境氛围** | 前景组顶层 | 主角心境:冷漠、亲密、惊吓、愤怒等心理感受 | 染整画(前景所有层 + 角色 + 后景) |
| **环境氛围** | 后景组顶层 | 世界基调:明暗、时间、天气、地点性 | 染后景区(后景主特效 + 场景后景) |

**为什么这样分**:心境氛围必须染整画,心理冲击才能成为整体感受;环境氛围只染后景区,保护前景场景与角色的色调独立性,让"主角与近景"和"远景世界"在情绪上可独立调度。

> 当前 测试版 中前景场景为空(都用后景),环境氛围实际覆盖了所有可见场景。当前景场景启用后,前景将不被环境氛围染色——这是设计取舍,见 §一 类型族关系。

### 3.2 预设的三字段结构

任何氛围预设由三个字段定义:

| 字段 | 语义 |
|---|---|
| **染色色调** | 给画面叠加什么颜色,含透明度 |
| **叠加方式** | 染色叠加的方式:**压暗类**(保留底色亮度、压暗色调)/ **提亮类**(提亮色调、出屏幕高光感)/ **覆盖类**(中性增对比) |
| **暗角强度** | 屏幕边缘渐变压暗的程度,0 = 无暗角 |

> 具体预设清单(色调数值、叠加方式选择、用途场号)由各落地版本维护。例如 测试版 的 9 个预设见 [测试版 / 氛围预设表.md](../02-测试版/氛围预设表.md)。
>
> 「把氛围预设结构本身纳入通用规范」是 **D1 候选**,见 [待讨论清单.md](待讨论清单.md)。

### 3.3 切换规则

- **切场景** → 环境氛围渐变到新场景的默认预设;心境氛围自动重置为空(避免上一场的情绪跨场污染)
- **段落推进** → 默认不变,剧情明确需要时才切
- **两层独立** —— 心境氛围与环境氛围各管各组,叠加而非替换;心境氛围入场时环境氛围不退

### 3.4 立绘差异度低时的协作模式

当立绘资产差异度不够(如同一姿态的微表情差分)时,单靠立绘切换玩家感受不到推进梯度。这时用 **心境氛围 + 节奏 + 特效** 三件套补强:

```
进度:        0% → 25% → 50% → 75% → 100%
环境氛围:    不动(保持场景基调)
心境氛围:    无 → 无 → 浅染 → 加深 → 退(让环境氛围接管)
立绘:        原图 → 原图 → 切图1 → 切图1 → 切图2
节奏:        停顿 → 停顿 → 停顿 → 慢推 → 收束
```

立绘单看几乎不变,配合心境氛围递进 + 节奏停顿 + 特效叠加,体验上有清晰梯度。

> 「低差异资产协作」是否抽象成通用方法论是 **D2 候选**。

## 四、特效层

### 4.1 哲学:克制 + 抽象

> 直接画出来的写实细节几乎一定廉价。能用粒子、光、震动表达的,就不画具象物件。

**允许 ✅**:

- 抽象粒子(鬼火、尘、字符浮起)
- 体积光(月光柱、阳光柱 —— 是「光」不是模拟物)
- 全屏动态(屏震、白闪、镜头推拉)
- 短促色彩失真

**禁止 ❌**:

- 在角色身体上画程序化线条(手腕画绳子、嘴角描红线)
- 写实物件矢量图(杯子、果子等)
- 卡通化 UI 弹窗与「+10%」飘字

**不要用粒子模拟具象物 ⚠️**:粒子的「点」化抽象 OK(鬼火 = 单点光),但**不要试图用粒子模拟具象的火焰 / 雾团 / 烟雾 / 血雨 / 水花**——团状颗粒模拟物会塑料感很重。具象冲击靠**整图素材闪现 + 闪 / 震 / 明暗变化** 实现:

- 烈焰救场 → 整图(红调场景)短暂叠加亮度 + 白闪 + 屏震
- 雾涌起 → 半透白板 + 提亮叠加 + 透明度渐变(不用粒子云)
- 撕碎瞬间 → 整图一帧闪现 ~0.3 秒(不用粒子血 / 水)

**判别标准**:**这玩意儿在现实里有具体形态吗?** 有 → 整图素材;没有(鬼火、尘、光柱)→ 粒子。

### 4.2 主导 / 交互 / 切换 三分类

| 类别 | 含义 | 占图层栈槽位 | 任意时刻最多 | 例子 |
|---|---|---|---|---|
| **主导** | 长生命的视觉信号,构成画面「特效元素」 | ✅ | 1 种(前 / 后二选一) | 鬼火、尘飘、月光柱、晨光柱、字符浮起 |
| **交互** | 与剧情节拍同步的瞬时全屏行为,不构成视觉「元素」 | ❌ | 任意叠加 | 屏震、白闪、镜头推拉、烈焰爆开 |
| **切换** | 开 / 关 状态切换 | ❌ | 任意叠加 | 雾、灯笼、纸扎人 |

> **判断标准**:**这个特效如果消失了,玩家会觉得「画面少了什么东西」** → 主导;**消失只是「动作没发生」** → 交互。

**主导特效的「前 / 后」**:每个主导特效声明时需指定挂载位置——角色之前(粒子飘过面前、字符浮在身前)或角色之后(背后光柱、远处雾)。位置由剧情表达决定,**任意时刻屏内只允许一种主导特效,且只在一侧**,不允许前后同时各挂一个。

**交互特效的位置**:交互类(屏震、白闪、全屏色块)覆盖至文字之上、交互 UI 之下——剧情冲击瞬间字也被吃掉,但圆弧仍可点。屏震 / 镜头推拉本质是对整个画面的位置 / 缩放变换,不占独立层。

> ⚠️ 「交互特效」≠ 用户操作的反馈。这里指的是**与剧情节拍同步触发的瞬时全屏特效**——位置在屏幕表面、跟交互 UI 同层,因此归名"交互"。用户操作反馈见 [交互设计.md §三 反馈动效原则](交互设计.md)。

### 4.3 「画里的字」作为特效层特例

某些剧情中需要在画面中浮现文字(古诗字符、咒语等),用墨迹由淡到浓 / 字符逐个浮起的视觉风格区分「画里的字」与「旁白文本」。**这是特效层唯一允许的「画文字」**。

> 此特例是否值得作为通用原则保留,见 **D3 候选**。

## 五、覆盖率口径

覆盖率 = **场景层占据画面的视觉比例**,用来在节奏曲线上量化每个时间点的「画面信息密度」。

### 5.1 四种状态

| 状态 | 计入 | 互斥关系 |
|---|---|---|
| 纯极暗底 | 0% | — |
| **单体集**(1-N 个) | 各单体面积累加(典型 20→70%) | 互斥组 A |
| **整图遮罩露出** | 遮罩面积百分比(典型 25→70%) | 互斥组 A |
| **整图全揭** | 100% | 互斥组 A |

**互斥组 A**(单体集 / 整图遮罩 / 整图全揭)三选一,**同时只能存在一种**。单体之间可叠加。

**前 / 后景的覆盖率口径**:覆盖率以**场景·后景**为主统计;前景作为遮挡装饰一般小面积出现,**不计入主覆盖率**(前景独立有无不影响节奏曲线的形状)。

### 5.2 设计目标带

| 时间占比 | 覆盖率区间 | 含义 |
|---|---|---|
| 约 50% | **20-30%**(探索期) | 单体或小遮罩出现,留白多,给玩家想象空间 |
| 中段 | **50-60%**(叠加期) | 多单体或遮罩扩大,画面信息变密 |
| 高潮 | **100%**(全揭) | 整图全揭,剧情冲击点 |

留白(0%)和半揭(40-60%)属于辅助状态,不应占据太长连续时间。

> 「节奏起伏曲线作为设计方法论」的口径定义是 **D6 候选**,见 [待讨论清单.md](待讨论清单.md)。各落地版本的具体曲线见各自实现(例如 测试版 的曲线见 [测试版 / 节奏起伏.html](../02-测试版/节奏起伏.html))。

## 六、画面声明(视觉变更指令)

> 用「状态机」描述这层会让人想到 Unity 的 Animator 状态机,容易混淆。这里改叫**画面声明** —— 每个剧情节拍上,只声明「哪些图层要变成什么」,其余图层保持。

### 6.1 核心原则:只声明改变量

每个剧情节拍上,可以**只声明改变的图层**,未声明的图层保持当前状态。这样做的好处:

- **简化剧本编排**:不用每个节拍重新写一遍所有图层的状态
- **降低出错概率**:不会因为漏写而把某层意外清空
- **保持图层独立性**:每层有自己的生命周期,不被其他层意外影响

### 6.2 声明指令清单

| 指令 | 参数 | 语义 |
|---|---|---|
| `场景前景 设置` | 单体 ID,或遮罩参数(形状 + 中心 + 半径) | 设置前景单体,或前景整图的遮罩区域 |
| `场景前景 清空` | — | 清空前景 |
| `场景后景 设置` | 单体 ID,或遮罩参数 | 设置后景单体,或后景整图的遮罩区域 |
| `场景后景 清空` | — | 清空后景 |
| `心境氛围 切换` | 预设 ID | 切换心境氛围到指定预设 |
| `心境氛围 清空` | — | 清空心境氛围 |
| `环境氛围 切换` | 预设 ID | 切换环境氛围到指定预设 |
| `环境氛围 清空` | — | 清空环境氛围 |
| `主导特效 启动` | 特效种类 + 挂载位置(前 / 后) | 启动一个主导特效 |
| `主导特效 清空` | — | 清空主导特效(不论前后) |
| `交互特效 触发` | 特效种类 + 持续时长 | 触发一次性交互特效 |

> 具体预设 ID、单体 ID、特效种类的命名由各落地版本维护。指令的语法表达(声明式数据、配置文件、可视化编辑器等)也由各落地版本选择。
>
> 「指令集合是否就是 Echo 通用 DSL」是 **D4 候选**。

### 6.3 默认行为

- **切场景节拍** = 触发场景前 / 后景与环境氛围切换;**心境氛围与主导特效自动重置为空**(避免上一场的情绪 / 特效跨场污染)
- **段间节拍** = 未声明的层全部不变

### 6.4 主导特效切换语义

声明新的主导特效时,如果已有主导特效在屏:**无论新旧的挂载位置(前 / 后)是否相同,旧的先淡出再上新** —— 任意时刻只允许一种主导特效在一侧。
